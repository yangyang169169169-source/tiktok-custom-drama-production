# 人物肤质、脸型与服装验收

2026-11-20 用户要求。适用于短剧 Skill 和改编 Skill 后续新写及获授权修订的人物设计、每套完整生成 Prompt、首图和后续造型验收。与旧版强调可见毛孔、只要求女主柔V脸或默认保守服装的表述冲突时，以本文件为准。更新规则不启动生图、不自动返修历史资产、不增加原有生成及返修次数。

## 1. 所有角色的肤质

- **默认白皙、细嫩、无瑕**：剧情或人设没有其他要求时，角色面部呈现白皙通透、细腻水润、肤色均匀的优质肤质；男女主和主要配角、主要反派均严格执行。普通面孔、贫困、劳动职业、反派身份及成熟气质均不构成粗糙皮肤、暗沉或瑕疵的依据。
- **白嫩与身份兼容**：未限定肤色的新角色默认选择白皙细嫩的肤色；明确的深肤色、族裔外貌要求、用户指定参考及已认可身份保留原有基础肤色，仍达到细嫩、匀净、健康、无非设定性瑕疵的同等级肤质。不得把已确认角色漂白或把白嫩做成失血苍白、灰白、过曝。
- **脸部优先，裸露部位一致**：无剧情或人设依据时，不出现雀斑、随机痣、痘痘痘痕、色斑、粗大毛孔、斑驳、暗沉、油腻高光、异常潮红、黑眼圈、眼袋或深泪沟。脸、耳、颈、肩、手与腿的肤色和细腻程度协调，不能只把脸修白或使三视图肤色不同。
- **细微肤理服务白嫩效果**：保留清晰五官、细微自然肤理及柔和光泽；不以粗大可见毛孔证明写实，也不使用蜡像感、塑料皮、模糊柔焦或强磨皮掩盖问题。成年、成熟和老年角色保留真实年龄与必要年龄纹理，不能统一幼龄化。
- **例外须精确**：伤痕、胎记、病伤、特殊肤色、年龄特征等按正式剧情、人设或已确认身份保留；在现有记录注明依据、部位及适用场次，只放开必要特征，其余皮肤仍保持优质肤质。临时污血、泪妆或伤势不永久写入所有服装母版。

## 2. 前10集人物覆盖

通读全剧建立角色／造型清单时，核对第1—10集实际入画的人物及其年龄阶段，含主要角色、配角、小角色和回忆中的可见人物；不足10集则核对全部集数。不能只查首集男女主或只查在前10集首次登场的人物。

在已有角色规划或验收表内简记“前10集出镜集数、肤色与肤质方案、例外依据、实际图片检查结论”。每个纳入本轮制作的角色资产落实本标准，不因戏少降低肤质要求。无需独立出图的NPC仍保留其镜头肤质要求和制作去向，不为本项额外生成图片。后续集数沿用相同质量标准。

## 3. 主要女性默认精巧柔V脸

- 适用于女主、女反派及其他主要女性角色。剧情或人设没有特殊外形要求时，默认脸盘较小、比例紧凑协调，面颊保有自然柔软体积，颊颌曲线柔和收窄，下颌窄于颧部，下巴短而圆润，形成自然女性化的柔V轮廓；不能仅女主执行、把女反派默认做成宽硬方长脸。
- 重点避免无依据的大脸盘、纵向长脸、过长中下庭、宽方下颌、厚方下巴、粗重眉骨，以及外扩高颧、凹颊和硬颌的叠加。冷艳、强势、女王、成熟、事业型或欧美背景均不自动成为男性化轮廓的理由；气场通过眉眼、目光、妆发与仪态表达。
- 在柔V审美范围内，用收束幅度、颊部体积、眉眼、鼻唇、发际线和成熟度拉开差异，保留独立五官；不批量复制同一张脸，不削成尖锥下巴、不机械缩头。明确的特殊外形、真实年龄和已确认身份按其依据保留，不能据此擅改锁脸母版。
- 每位适用角色的完整 Prompt 写出自己的脸部长宽、颊颌过渡、下巴形态及五官组合，不能只写 `beautiful` 或 `feminine`。首图实际看正面、三分之四面及头颈肩比例，确认转面后仍柔美，不用遮发、浓妆或拉伸图片掩盖脸型。

## 4. 男主及主要男配角的脸型和骨相

- **适用所有主要男性**：男主、主要男配角及主要男反派，剧情或人设无特殊外形要求时，均以顶级男性模特或男性演员的脸型、骨相与五官协调度作为选角参考，避免脸太长、太方、太大。不能只给男主执行，也不能为区别配角而故意放大脸盘、拉长中下庭或加重方颌。
- **每个新身份先实际看参考**：按本剧年龄、时代地域、身份和气质，从既有本地库及可访问的选角来源选适配的顶级男模／男演员清晰正面和三分之四照片，按共享参考规则同步研究小红书。记录参考对象、真实来源、实际看过的脸型骨相、选用理由与具体借鉴部位；不靠姓名、名气、搜索摘要或只写“顶级男模脸”代替实际看图。候选本身若明显方大、纵长或下颌厚重，不因其知名度直接照搬；未取得可用原图时标记研究未完成，沿用既有研究和生成边界。
- **比例精练，保留自然男性气质**：设计协调的面部长宽与上中下庭、颧宽和颌宽、下颌转折、下巴长度体积及头颈肩关系；骨相立体有清晰度，脸盘不过大，中下庭不过长，下颌不过宽方，下巴不过大或前突。可保留适量棱角和成年男性特征，不把所有男性改成女性柔V脸、尖下巴或幼态脸。强势、霸总、黑帮、军人、成熟或反派身份不自动对应大方长脸和粗重骨骼。
- **参考优点，形成独立面孔**：提炼适配的脸型比例、骨相转折和眉眼鼻唇关系，协调成本剧各自的原创演员脸；参考人名与出处留在研究记录，最终 Prompt 写可见结构，不直接复制某位明星整张脸或把所有角色做成同一位男模。保留同剧和跨剧差异，差异在协调的比例范围内完成，不能用加大、加方、加长面孔凑区别。
- **完整 Prompt 与实际图都检查**：逐套明确本人的脸部长宽、颧颌、中下庭、下巴及独立五官；检查泛化的 `masculine`、`chiseled`、`powerful` 或重骨相描述是否又把脸推大、推方、推长。实际查看正面、三分之四面和全身头颈肩比例，首图与后续造型均适用，确认立体、精练、上镜且仍为同一身份。不以西装、肌肉、胡须、发型、低头姿势或硬光掩盖脸型；未通过的基准不扩展依赖图，按已有授权与返修次数处理。
- 正文明确的特殊外形、真实年龄、用户指定方向及已认可身份按其依据保留，儿童使用合龄脸型参考。规则用于后续新建及获授权修订，不自动替换历史锁脸母版。

## 5. 成年主要女性的露肤与曲线

- **默认提高露肤度并显出曼妙、火辣的成年女性曲线**：适用于已明确成年的女主、女反派及其他主要女性，剧情、人设和场合无特殊限制时主动执行。不能只写“高级、时髦”后仍默认宽松遮体、高领长袖，或把善良、淑女、母亲、职业身份直接译成全身保守包裹。
- **逐套落实可见设计**：按本套年代、地域与场合选择合适的露肩、锁骨、手臂、背部、腰侧或腿部留白，并以合身剪裁、收腰、省道、结构裁片、贴合垂坠或开衩呈现胸腰胯曲线和修长四肢。可用方领、适度低领、露肩领、无袖、露背或适当裙长等具体设计，不要求每套全露同样部位，也不规定露肤百分比。
- **身材与衣服同时成立**：人物保持成人年龄、自然丰满度、协调胸腰胯与纤长线条，衣服能显出已设计的曲线。不能全员同款沙漏体、极端丰胸、细到失真的腰或拉长四肢；新造型锁定既有体态，不能靠换装更换身体。
- **剧情限制准确执行**：寒冷防护、宗教或职业穿戴、明确保守人设、伪装、战斗防护等有依据的场合保留必要覆盖，并在许可范围内用腰线与剪裁体现身形，不擅改故事、制服或时代。普通校园背景不证明成年；儿童、未成年人及年龄未确定者使用合龄衣着与体态，不套用性感、火辣、丰胸或提高露肤的成人规则。年龄未明先查正文与已确认资料，只暂停依赖成人化设计的部分。
- 在已有造型规划中记录“本套露肤部位、曲线由何种剪裁呈现、胸部遮盖结构、剧情限制依据”，写进每套完整 Prompt。衣饰参考中的成年模特或较高露肤度，不自动证明角色年龄或授权改变既定身份。

## 6. 所有角色均不得露点

- **男女、年龄及角色级别一律适用**：任何视图均不能露出乳头或乳晕，也不能透点、走光或展示生殖器；剧情中的沐浴、换衣、亲密、受伤或男性展示肌肉均不构成露点例外。保留剧情事件，以服装、浴巾、被褥或合理构图遮盖呈现，不擅改源剧本的事实。
- **遮盖写清结构**：胸前对应区域必须由稳定、不透的实料或内衬覆盖。低领、露背、露肩或开衩可保留，蕾丝、薄纱、镂空与湿衣在相关部位必须有不透明内衬或覆盖，检查正面、三分之四和其他实际视角。不能只写 `no nudity` 后默认衣服一定安全，也不依赖头发或偶然手势防走光。
- **男性同样执行**：不把赤裸上身、全开衬衫或敞胸直接作为默认肌肉展示；需要展示肩臂、腹肌时，按剧情设计遮住乳头与乳晕的背心、上衣、内搭或稳定遮挡，不因“男性露点常见”放行。
- **提高露肤度不改成全身包裹**：在维持胸前不透明覆盖的前提下保留合适的肩、臂、背、腰及腿部留白与曲线，避免用一律高领长袖的方式完成遮盖检查。

## 7. 完整 Prompt 与实际验收

每套最终 Prompt 均完整展开适用要求，不让执行者另行拼后缀。以下是表达示例，按实际身份、年龄、肤色和服装改写；含剧情特征时删除冲突词：

- 肤质：`luminous, supple, delicately smooth and evenly toned blemish-free skin, subtle fine natural skin microtexture, clear facial detail, soft healthy sheen, no coarse enlarged pores, no waxy or plastic skin`。适用白皙默认的角色同时明确 `fair, luminous complexion`；明确深肤色者写其准确基础肤色与同等级细嫩肤质，不机械加入 `fair`。
- 主要女性脸型：`a small refined face with compact balanced proportions, softly rounded cheeks, a gently tapering V-shaped jawline and a short rounded chin`，再展开本人的独立眉眼鼻唇，检查其他结构词没有把面孔推宽、推长或推硬。
- 主要男性脸型：按实际参考转译为 `a refined, proportionate masculine face, balanced facial length and width, a well-proportioned midface, defined but restrained cheekbone and jaw structure, a proportionate chin`，再写本人的具体骨相与独立五官；不能只复制此句，也不在最终执行词中用明星姓名替代结构设计。
- 成年主要女性造型：明确 `adult woman` 及已确认年龄，按本套实际写出显露部位、合身剪裁和协调的曲线，例如 `an off-shoulder fitted dress with a sculpted waist, a naturally curving adult silhouette, opaque fully lined fabric securely covering the breasts`；不把示例礼服复制给所有场合。
- 所有角色遮盖：按实际服装写明不透明覆盖，并完整表达 `nipples and areolas fully concealed in every view by secure opaque coverage, no exposed nipples or areolas, no see-through exposure, no genital exposure`。未成年人只用合龄服装与遮盖描述，不加入成人身材或露肤示例。

生成前核对参考与完整提交词；生成后实际逐张查看常规定妆板中的清晰面部、正面及三分之四全身，必要时查看原图对应部位。分别记录肤质、女性脸型、主要男性的脸型骨相与参考落实、适用的成年曲线与露肤、所有角色不露点的结论；前10集覆盖另对账。不能以 Prompt 写了要求、图片清晰或文件齐全代替看图通过。

任一适用项失败即标记该资产待修，定位肤质词冲突、参考继承、脸型结构、服装版型或遮盖问题，按已有授权及返修次数定向处理；基准未通过不扩展依赖造型。这里只完成规则或 Prompt 时报告“图片未生成／未核验”。继续只交付常规定妆图，不另生成、裁切或交付独立 `UpperBody` 文件。
