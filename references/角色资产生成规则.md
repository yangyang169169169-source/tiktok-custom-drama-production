
客户正式剧本完成校对、确认并通过安全检查后，使用当前环境可用的图片生成器生成角色的写实电影级定妆资产。开始前必须确认权威剧本文件和角色资产状态；不得依赖旧改编大纲、固定项目状态卡或某台电脑上的专用目录，也不得用程序批量编写 Prompt。

先读取同目录[资产规划与按需生成规则](资产规划与按需生成规则.md)及[人物选角与跨剧差异化](人物选角与跨剧差异化.md)。后者第3节规定逐角色的骨相五官、发际线发型、妆容仪容、神情及身形体态细化，第4—6节规定同剧易混人物和跨剧对照、完整 Prompt 及实际看图验收；规划、生成与验收均须落实。本文件的图片命名、Prompt 和三联板要求适用于生成清单；剧情状态与无需出图的需求放在规划／调用表中，不逐条生成图片。

人物设计、完整 Prompt 与实际图片还须执行[人物肤质、脸型与服装验收](人物肤质脸型与服装验收.md)：默认白皙细嫩无瑕，主要女性默认小巧柔V脸，成年主要女性按场合提高露肤度并显出协调曲线，男女均不得露点；前10集出镜角色逐项核对。

### 固定目录与命名规范

角色概念图采用以下项目相对目录：

```text
[项目剧本目录]/
├── character_prompts.md
├── character/
│   ├── 01_MarisolVega_01_HotelUniform_Ep01-10.png
│   ├── 01_MarisolVega_02_EveningGown_Ep11-25.png
│   └── 02_DiegoSantos_01_BusinessSuit_Ep01-20.png
└── 归档/
    └── YYYYMMDD_HHMMSS_[简短原因]/
```

* `character_prompts.md` 直接放在项目剧本目录根部，为唯一当前角色提示词文件；修改前的旧版只进归档，不在根目录保留多个权威版本。
* 角色图片统一放入项目剧本目录下的 `character/` 文件夹。
* 角色图片文件名统一使用 **`角色编号_角色名_造型编号_造型名_第几集.png`**，例如 `01_MarisolVega_01_HotelUniform_Ep01-10.png`。
  * `角色编号` 必须与 `character_prompts.md` 中的角色序号一致，使用两位数字。
  * `角色名` 使用英文名或无空格英文 Slug，避免空格和特殊符号。
  * `造型编号` 使用两位数字；`造型名` 使用简短英文 Slug。
  * `第几集` 使用 `Ep01`、`Ep01-10`、`Ep36-50` 等格式。
  * 连续使用同一造型时用半角连字符表示范围，例如 `Ep02-14`；中间断开的非连续集数必须用中文顿号 `、` 分隔，例如 `Ep02、Ep50`，不得写成 `Ep02_Ep50`、`Ep02+Ep50` 或用逗号连接。
  * 集数只记录该造型在正式剧本中**实际可见出镜**的集数。角色仅被对白提及、出现在报告/名单中、以纯画外音出现或只存在于他人说明时，不计入造型覆盖集数。
  * 非连续出镜不得把最早集与最晚集扩写成虚假的连续范围。例如只在 Ep02 闪回和 Ep50 闪回出现的造型，应写 `Ep02、Ep50`，不得写 `Ep02-50`。
* `character_prompts.md` 的生成清单中，每个需要图片的条目使用同一套编号与集数命名。条目标题必须是最终图片文件名的无扩展名版本，最终图片文件名 = 条目标题 + `.png`，均包含角色编号、造型／参考编号和 `Ep` 集数范围。免生成状态只进规划表；局部或姿态参考用用途明确的变体名，不计为新增服装。
  * 条目标题格式：`### 01_MarisolVega_01_HotelUniform_Ep01-10`
  * 条目字段只保留：`涉及场次`、`面孔锁定参考图`、`Prompt`
  * `涉及场次` 只写正式剧本中的场次编号，并按剧本顺序用中文顿号 `、` 连接，例如：`1-1、1-3、2-1、3-2`。场号本身已包含集数，不得再写 `EpXX：`、按集分组或使用分号；也不得重复场景名、剧情概述或人物动作。
  * 不再重复列出 `角色编号`、`角色名`、`造型编号`、`造型名`、`覆盖集数`、`建议文件名` 等已在条目标题中表达的信息
* `character_prompts.md` 语言规范：除角色英文名、条目标题、最终图片文件名、图片路径、`Prompt` 正文和 `出场字卡文案` 表格中的英文字卡短语外，其他字段名、说明文字、调研摘要、脸谱差异表、造型清单和检查结论必须使用中文。
  * 不得在 `Prompt` 正文之外使用 `Face Lock Reference`、`Character ID`、`Outfit ID`、`Coverage`、`Suggested Filename`、`Description` 等英文元信息字段。
  * 造型名作为文件名 slug 时可用英文；解释该造型的剧情阶段、服装逻辑、调研依据时必须用中文。
* `character_prompts.md` 末尾必须追加 `## 出场字卡文案`，用于后续视频人物首次出场时的姓名下方字卡。每次生成或重写 `character_prompts.md` 时都必须生成该段，且必须放在文件最后，不能省略、不能另建文件、不能只在回复里说明。字卡格式参考用户提供的图片：标题为 `出场字卡文案`，三列表格依次为 `角色名`、`字卡短语（英）`、`首次出场`。字卡文案不是人物简介，不写长句，不写剧情说明，只写观众能在 1 秒内识别的**客观身份英文短语**。字卡只回答“这个人客观是谁”，不回答“这个人在剧情中做了什么”或“观众应如何评价他”。表格使用中文表头，字卡短语内容使用英文：

  ```markdown
  ## 出场字卡文案

  | 角色名 | 字卡短语（英） | 首次出场 |
  |---|---|---|
  | Evelyn Hart | Aviation Engineer | Ep01 |
  | Nathan Cross | University Researcher | Ep01 |
  | Veronica Vale | Base Press Officer | Ep01 |
  | Ryan Wolfe | Navy Pilot | Ep01 |
  ```

  * `角色名` 必须与角色设定和 Prompt 条目中的英文角色名一致。
  * `字卡短语（英）` 建议 2-5 个英文词，使用 Title Case，不写句号，不写完整句。
  * `首次出场` 使用 `Ep01`、`Ep07` 等格式，以正式剧本中该角色第一次真正出场为准。
  * 只写观众当集可知的客观身份；若真实身份是后续反转，不得提前剧透，改写首次出场时公开可见的职业、职位、机构身份、家族身份、亲属关系、社会身份或神祇职能。
  * 字卡短语必须是可直接上屏的英文客观身份标签，优先写职业/职位/机构身份/家族身份/亲属关系/社会身份/神祇职能，例如 `Vale Global Temp Worker`、`Company Chairman`、`Family Heiress`、`Emergency Specialist`、`Condo Sales Supervisor`、`Olympian Messenger God`。
  * 禁止写剧情处境、关系功能、人物评价、命运状态、爽点标签、营销口号、抽象气质词或完整句；不得使用 `Betrayed Heiress`、`Ruthless Protector`、`Jealous Rival`、`The Thief Of Miracles`、`The Heir Who Kneels For Mercy` 这类文学化/剧情化短语。
  * 优先覆盖主角、核心配角、主要反派和需要屏幕字卡介绍的重要功能角色；普通群演、无名士兵和路人群像不强制生成。
* 不再按角色拆多层文件夹；同一角色的不同造型用文件名区分即可。
* 返工前把将被修改的 Prompt 文件及受影响旧图片归档到 `归档/YYYYMMDD_HHMMSS_[简短原因]/`，保留可追溯版本，不覆盖旧备份。若已有资产变更日志则追加记录，否则在交付说明中记录；不强制创建大纲或项目状态卡。只更新受影响条目及引用，已合格的无关图片保留。

### 第一阶段：人物造型清单整理（必须先行）

生成前，AI 必须先通读完整剧本，整理所有角色在各场次中**实际可见**的造型与状态，确保不漏换装，也不把连续戏误拆成多套服装。客户没有角色视觉设定表时，从正式剧本建立选角简报，同步查本地人脸库与小红书，实际看图并比较选角参考，再提炼“短剧视觉主菜、第一眼吸引力、关系功能、脸部钩子、身材气场、服装签名、必须避免”，不得跳过研究套用默认美人脸，也不得要求补写改编大纲。

0. **全剧人物视觉总纲（步骤2首个交付门）**：设计单个角色前，必须先根据正式剧本建立全剧统一的人物视觉系统，并写在 `character_prompts.md` 最前面。它只服务资产设计，不另建大纲或人物小传。

   * 总纲必须明确：题材、时代、地区、目标受众、真人写实程度、角色定位与差异化颜值要求、统一制作质感、年龄层次、脸谱分布、身形轮廓层次、核心服装廓形、主材质、全剧色彩结构、角色专属色/纹样、主要关系组的视觉对比和全剧共同禁止项。
   * 设计优先级为：剧情及时代地区等背景设定 > 角色身份、职能与观众应有的第一印象 > 与该角色相适配的颜值、气质和吸引力。主角、核心恋爱对象在不违背人设时保持高颜值和较强镜头吸引力；反派、小配角、NPC及功能型角色不强制非常高颜值，以辨识度、可信度和定位清楚为重点。高颜值反派可按剧情保留，普通或有鲜明个性特征的面孔也可使用，不因正反派标签一律美化或丑化。所有角色保持精良的摄影、材质、清晰度与身份一致性。
   * 年龄、族裔、国籍和身体状态以剧本及用户明确要求为准，不因“欧美受众”自动把所有人设成同一族裔，也不得把某一族裔固定分配给反派或底层角色。
   * 全剧色彩不得变成所有人同穿黑色、同一饱和度或同一单色系。女性反派可以在符合剧本的前提下提高服装饱和度，但必须与女主形成明确而不俗艳的对比。
   * 关系组必须成对规划：男女主、女主/女反、男主/男配、家族成员、上下级或阵营对手，分别明确脸部、身形、色彩、材质和轮廓上的对比，避免单独看都好看、放在一起却像同一模板。
   * 总纲确认后，后续角色视觉主菜卡、脸谱差异表、造型清单和 Prompt 必须服从它；若单角设计需要突破总纲，先说明剧情理由并更新总纲，不能临场漂移。
   * 输出采用以下紧凑格式，与角色视觉主菜卡、脸谱差异表、服饰调研摘要及造型清单一起形成规划稿；按已有审阅安排和授权进入 Prompt 组装，不重复申请同一授权：

     ```markdown
     ## 全剧人物视觉总纲

     | 项目 | 统一口径 |
     |---|---|
     | 题材/时代/地区/受众 | ... |
     | 整体选角与真人写实程度 | ... |
     | 年龄层次、角色定位与差异化颜值要求 | ... |
     | 脸谱与身形分布 | ... |
     | 服装廓形、材质与工艺 | ... |
     | 全剧色彩及角色专属视觉符号 | ... |
     | 主要关系组视觉对比 | ... |
     | 全剧共同禁止项 | ... |
     ```

1. **先规划精准换装，再判断数量**：在原连续性表记录 `场次／故事时段 | 场合与换装机会 | 剧本证据／美术依据 | 人设与视觉作用 | 新增／复用／重搭的母版 | 状态及制作方式`。可与共用规划／调用表合并，不重复建表。

   * 不设主角或配角套数上限、最低指标或每几集必换；先检查主要角色的生活可信度、阶段表达、服装辨识度及全剧视觉丰富度，再检查无收益重复。
   * 同一连续行动、同一地点链且没有离场换装机会时沿用当场服装；回忆复用相应历史造型。不得因跨集、场景标题、情绪或旧标签变化擅自换衣。
   * 跨日、换场和真实换衣都不机械触发新增或复用。根据剧情阶段、场合、季节、角色生活条件、衣物来源和视觉表达安排。剧本没有列明款式时，允许符合设定的美术新增；重要亮相、关系变化、生活阶段和避免主要角色长期单一均可构成具体理由。真实换干衣必须保持换前换后的区别，但不预设选旧衣还是新衣。
   * 外套穿脱、披肩／头纱增减、湿身、污损及能力表现先归入对应母版的状态或层叠组合。记录差异后按轮廓、遮挡及镜头稳定性决定是否补局部或必要派生图；同衣不等于无须参考，也不自动产生整套三联图。
   * `Fallen`、`Exiled`、`Stripped`、`Condemned` 等造型名只表达身份或剧情阶段，不自动等于破衣、脏污、伤痕或狼狈；视觉状态必须有剧本证据。
   * 不得为凑数量重复生成没有视觉收益的造型，也不得因同属礼服、西装或颜色接近就合并。不同剪裁、材质、配色和亮相意义可以保留；新增与复用的依据须写入规划表。
2. **选角图片研究与角色视觉主菜卡（必须先行）**：在脸谱差异表和造型清单前，先按[人物选角与跨剧差异化](人物选角与跨剧差异化.md)为新主要角色形成选角简报，按[共享主演参考库](共享主演参考库.md)实际查看用户原图与适配的同类选角参考，按人设开展网络研究，在 `character_prompts.md` 记录“选角参考与原创转译”；再为主角、核心恋爱对象、核心反派和高频核心配角建立“角色视觉主菜卡”，明确这个角色第一眼到底卖什么。已有合格身份母版不因后续换装重复选角；新身份图片研究未完成时可做暂定规划，但不宣称完成或启动首图生成，当次明确要求离线／跳过研究的除外。

   * 每个角色必须先回答：这个角色的短剧视觉主菜是什么？观众第一眼应感到什么？该角色在关系、欲望、压迫、保护、嫉妒、反杀或身份反转中承担什么功能？
   * 不得把种族、肤色、国籍、贫困、职业、地域、外貌、体型、年龄或残障当作邪恶、低智、肮脏或低等的视觉速记；人物美感、阶层与道德价值必须分离。
   * 主菜卡必须包含：角色、短剧视觉主菜、外貌类型及剧本／美术依据、观众第一眼应感到、关系/欲望功能、脸部钩子、身材与气场、服装签名、必须避免。女主须明确适合本剧的类型，男主同样按人设定制；类型不替代具体骨相五官，也不按项目机械轮换。
   * “脸部钩子”不能只写 `handsome`、`beautiful`、`attractive` 等泛化词，必须写出由参考研究转译的独立骨相、眉毛和五官记忆点；气质气场与眼神要写出可见表达，不只贴“温柔”“冷艳”标签。
   * “服装签名”必须写出该角色区别于同剧其他人的稳定视觉符号，不能只写职业制服、礼服、西装、古装等泛化类别。
   * 核心恋爱对象在设定允许的范围内突出观众可感知的恋爱吸引力及相应关系张力；正文明确的普通外貌或特殊状态优先，不能仅凭职业、阶层标签擅自降低或拔高颜值。
   * 主菜卡用于生成和审查，不要求写成长篇人物小传；每格应短、准、可转化为视觉 Prompt。
   * 主菜卡概括方向，不能替代具体外貌。另在同一规划区按[人物选角与跨剧差异化](人物选角与跨剧差异化.md)第3节逐角色完成“角色外貌细化”：骨相、眉眼、鼻唇、肤色年龄感、发际线发型发色、妆容仪容、惯常神情、身形体态及辨识组合。每项写可见选择与原文或美术依据；男女同等细化，稳定身份、可变妆造和当场状态分开。
   * 反派及功能型角色先明确观众当场应辨认的身份、职能、地位和气质，再转成具体的脸部特征、年龄感、服装剪裁／徽记、发型、姿态或表情锚点；不能只写 `villain`、`doctor`、`guard` 等标签，也不统一套凶脸或高颜值脸。隐藏反派、伪装身份和后续反转按观众此时可知的信息设计，不提前泄底。
   * 小配角和 NPC 在既有规划或 Prompt 中用少量有效视觉锚点明确定位即可，不因本规则额外编人物小传、增加独立资产或扩展主角级造型清单。
3. **脸谱差异表（必须先行）**：在输出造型清单前，必须先为主角和核心配角建立“脸谱差异表”，避免男主/男配、女主/女配撞脸。

   * 同一性别主要角色之间至少 **5 项明显差异**，应包含脸型骨相及眉眼、鼻部、口唇中的至少两项结构区别；发型与发色分别检查。另对照身形体态、妆容和神情，不能靠服装、眼色、妆容或抽象气质凑结构差异。主配角、配角之间和实际易混的跨性别人物均按[人物选角与跨剧差异化](人物选角与跨剧差异化.md)第4节对照，记录最易混对象及图片核验状态；亲缘等必要相似或锁定相同发色时保留设定，不为凑数改剧情。
   * 所有人物以**原创虚构演员脸**为目标；允许并要求新主要角色研究真实演员、公众人物和影视角色参考图，选择性借鉴优秀视觉特征，再按本剧设定原创转译。研究参考不等于完整身份复制，参考人物姓名留在研究记录，生成 Prompt 使用具体特征描述。
   * **避免固定明星锚点**：不默认围绕任何单一明星选角，不把同一个明星姓名反复写入所有男性或女性的正负 Prompt。旧版固定 Henry Cavill 排除句不再作为统一后缀；通过正向骨相、眉眼鼻唇和头发设计实现独立面孔。
   * 若某角色结果过度贴近单一参考、与同项目角色明显撞脸，或沿用近期项目的整套选角风格，先定位设计／参考原因并修改受影响角色，再在既有授权与返修范围内处理；未通过母版不继续扩展。研究对象不同不代表实际结果已不同。
   * 新剧男女主须与可访问的近期相近项目进行跨剧主演对照，记录实际参考及差异；无历史图片不虚填视觉通过。不能复用别剧主演身份参考或只换服装、妆容、眼色制造新角色。具体范围和处理遵循[人物选角与跨剧差异化](人物选角与跨剧差异化.md)。
4. **服饰造型调研（必须先行）**：按故事时代、地区、年龄、阶层、职业、角色定位和场合，按[共享参考规则](共享主演参考库.md)同步查服装参考库和小红书，实际比较廓形、剪裁、面料、配饰及完整搭配，选出最适合本场的参考。资料受限时，注明实际查看的来源与缺项。

   * 每个主角和核心配角至少提炼 **3-5 个服饰设计锚点**，例如：地域纹样、阶层面料、职业功能结构、家族徽记、时代剪裁、宗教/仪式饰物、手工刺绣、珠宝材质、鞋履或发饰细节。职业功能结构只指制服口袋、扣件、肩章、胸章等服装本体细节，不得借此加入手持工具或独立道具。
   * 服饰必须切合角色身份与剧情阶段。豪门、王室、财阀、明星、女王型角色要有高级定制感、精密剪裁、面料层次和设计记忆点；平民、工人、单亲母亲、底层角色也必须有独特细节，如旧衣叠穿、地方织物、手作配饰、职业功能口袋、家传小物，不能只写“普通衣服”“朴素裙子”。
   * 男女主及其他核心角色按下文“主要角色服装审美与阶段设计”研究适配的时装、影视服装及奇幻造型参考，实际看剪裁比例、材质、配色、妆发与整体效果，不只查职业制服或通用礼服；把本套设计重点及剧情阶段依据并入既有服饰调研和造型规划。
   * 不得把所有角色都写成同一种高定礼服、黑西装或普通影棚职业照。造型设计必须服务“这个人是谁、处于什么阶层、正在经历什么剧情阶段”。
   * 女性角色逐套执行下文“女性角色配饰搭配”，在既有造型规划中记录领口／场合、项链、耳饰、其他必要配饰及搭配理由；项链与耳饰分开判断，主动留空也须明确，不以未写代替设计决定。
5. **标准定妆状态铁律**：角色概念图用于建立可复用的标准角色资产，默认服装、妆容、发型和配饰必须保持完整、干净、正常、可拍摄状态。

   * 禁止默认生成破损衣物、血污、泥污、伤痕、红肿、泪痕、哭花妆、烟熏火烧痕迹、过度疲惫病容等剧情状态化处理。
   * 角色处于平民、底层、劳动阶层时，也应通过面料、剪裁、叠穿、颜色、配饰和职业功能细节体现身份，而不是通过脏乱、破烂、受伤来表达贫穷或困境。
   * 剧本或用户规定的受伤、湿衣、伪装等状态必须登记，是否单独出图按共用规则判断；不要求用户再次逐一指定状态。基础母版不携带临时伤痕，必要状态图在名称中标注原因，并限定部位、出现与消失条件。
   * **双手空置铁律**：角色概念图默认只表现人物、服装、发型、妆容和固定服饰细节。三联设定板中的两个全身视图必须双手自然下垂、完全空置、手指可见，不得手持、抓握、托举、倚靠或触碰任何武器、工具、乐器、文件、手机、杯子、箱包、信物或其他可独立生成的道具。
   * **人物与道具分离**：职业、权力和身份优先通过服装剪裁、制服徽记、纹样和固定饰件表达。号角、手杖、武器、文件、酒杯等独立物件转入步骤4登记并按用途判断是否出图，不能因从人物图移出就自动生成一张道具图。与服装不可分离的徽章、纽扣、腰带扣和结构性饰件可以保留。
   * **身体状态优先于统一站姿**：轮椅使用者、卧床者、截肢者、拄拐者、孕晚期角色、严重伤病者或其他会直接改变姿势/行动方式的角色，必须采用符合剧本状态的自然坐姿、卧姿或支撑姿势，不得为了套模板强迫站立。普通角色仍使用自然站姿。
   * **辅助设备例外**：轮椅、义肢、固定支具等可以随人物出现。需要独立合成、多角度或特写时，再在步骤4补物件参考并共享设计；长期复用本身不强制重复出图。双手空置规则在身体状态允许时执行，不为展示设备制造夸张姿势。
6. **造型差异服务剧情与美术表达**：同一角色可因剧情阶段、场合、人设、关系、季节和视觉节奏安排不同服装；不为换而换，也不因已有服装勉强可用就拒绝有价值的新增。

   * **造型集数标识**：连续集数写 `Ep01-10`，非连续集数用中文顿号连接，如 `Ep02、Ep18、Ep50`；同一集内发生真实换装时，按画面出现顺序写 `Ep12A`、`Ep12B`、`Ep12C`，换回原造型可写 `Ep12A、Ep12C`。例如：`01_Mara_03_PrisonLook_Ep01-11、Ep12A`、`01_Mara_04_WardenUniform_Ep12B、Ep13-20`。
   * 需要独立图片的能力、变身、受伤等派生条目可以与基础服装重叠，名称须明确状态或参考用途，并只写状态实际出现的集数。免生成状态在规划表记录，不建立虚假的 PNG 条目。
   * 首套造型是面孔锁定母图，不等于覆盖角色从首次出现到最后出现的全部集数；母图标题仍须填写该套服装或状态真正出镜的集数。
   * 交付前必须扫描同一角色的集数重叠。每处重叠都要能由“同集真实换装”“闪回/现实并行”或“状态叠加”解释；无法解释的重叠必须修正后再交付。
7. **面孔与服装母版锁定铁律（Face / Outfit Lock）**：同一角色的所有造型必须看起来是同一个演员本人；同一基础服装的状态变体还必须保持服装结构、材质、纹样、扣件和颜色不变。

   * 使用已认可的清晰身份母版；没有可用母版时先生成并验收。首场遮脸、受伤图不作为唯一辨脸依据，优先用清晰的常规定妆图；确有缺口时补齐可辨认的常规定妆图。成年、童年及特殊形体各用相应阶段基准，不能用成年身形覆盖儿童。
   * 同年龄独立新造型直接用已确认的常规定妆图锁脸，说明参考图中对应的脸部、体态和服装视图，Prompt 中明确写入 `same person as reference image, identical facial structure, identical facial proportions, same eyes, same nose, same lips, same jawline, same hairline, same age, same body build and proportions, only change the specified outfit, hairstyle, makeup and accessories`；年龄、发际线或形体有剧情变化时按相应基准改写，不保留冲突句。
   * **锁脸与配饰分开**：独立新造型的身份参考只继承身份，不默认继承原图项链、耳环或其他配饰。在参考用途及完整 Prompt 中明确本套保留、替换与不佩戴的项目，防止同一母图首饰被复制到全部服装。同衣派生图则继承当套已确认配饰；只有剧情摘戴、损坏、转交或已授权设计变化时才改，并更新连续性记录。
   * 只有需要生成的同衣派生图才配置出图参考，使用对应服装母版；需要继承前一状态时可附其图，明确各参考的作用及哪些变化继续保留。写入 `preserve the exact same costume construction, materials, colors, trims and hardware; change only the stated condition`，不得仅锁脸后重新设计服装。免生成状态在调用表绑定母版和状态即可。
   * 后续造型不得只靠文字描述重新文生图；若当前工具无法使用参考图，必须暂停并向用户说明“无法保证同一面孔”，不得继续批量生成。
   * 若后续图发生明显面孔、年龄或体态漂移，先修错误参考／Prompt，再选编辑或重生；不得作为正式资产继续传播，不用同一失败方案盲目重试。

7. **具体设计进入每条完整 Prompt**：先写整套全身廓形、衣长和腰线、内外层的关系及主辅色落点，再写面料的重量与表面、局部工艺、鞋履和饰物，明确与本套衣装配合的发型和妆容。远景重点与近景细节不能只留在规划表；`couture`、`luxurious`、`bold`、`stylish`或`high fashion`不能代替它们。清理无剧情依据的`plain`、`understated`、`minimalist`、`conservative`、`matronly`、`dowdy`、`shapeless`等默认素淡／老化描述；有设计的极简和剧情要求的低调准确保留，不一律删除。白棚中性光下也应看清设计，不能借场景、彩光或姿势装饰掩盖普通服装。

### 女性角色配饰搭配

适用于女主、其他女主及女性配角；主要女性角色逐套落实，低频配角可并入已有造型说明，不为配饰额外扩展角色资产数量。目标是让配饰与服装相互衬托、锦上添花。规划、Prompt 和实际图片都要落实，不能只在总说明中写“配饰精致”。

1. **先看整套，再分别决定**：依据剧情、时代地区、人设年龄、生活条件、服装风格及当场活动，分别判断项链、耳钉／耳环／耳坠的有无与款式，再按需要考虑戒指、手链、胸针、发饰等。可以只戴耳饰、只戴项链、两者都戴或全部留空；不把女性、高颜值、豪门身份或正式场合作为必须戴满首饰的理由。服装与配饰的年轻感、成熟度须贴合当前项目，不把校园、青春或日常造型机械搭成成熟职业或贵妇风。
2. **按领口选择项链及落点**：结合领口开口、裸露面积、布料纹样、刺绣珠饰和已有视觉重心判断。剧情与人设允许时，露肩、抹胸、方领、V领等若显空、整套缺少呼应，应主动设计合适的项链，写清链长、粗细、吊坠尺度与胸前落点，使它与领口线条和留白协调；不因露肩就一律加项链。高领、领结、复杂领饰、重刺绣或已有珠饰重点的服装可留空；睡眠、运动、劳动等造型按实际情境判断，不能把“日常少饰”变成一律禁饰。项链不压住领口关键结构，不与衣领切线、堆叠打架或显得突兀。
3. **耳饰独立搭配，并安排主次**：根据服装、发型露耳程度、脸部轮廓、领口和场合选择耳饰长度、形状与体量；有项链不等于必须配耳环，无项链也可用耳饰建立视觉重心。项链与耳饰同时出现时协调金属色、宝石／珍珠色、造型语言和分量，避免两个强装饰互相争抢；可以呼应而不必是成套首饰。手链、戒指、发饰等同样按实际效果取舍，不为“完整搭配”把每个部位填满。
4. **有变化，也允许合理复用**：不同造型与角色按各自设定选择，不把同一条项链、同款耳钉或一整套首饰复制给全部女性，也不要求每套必须换新。日常习惯、同一连续场次或服装搭配合理时可复用；变化须有搭配收益。款式、材质、颜色与服装剪裁、面料、扣件及整体气质呼应，不用昂贵珠宝统一表示漂亮或贵气，不凭空给首饰添加家传、定情等剧情含义。
5. **剧情饰物单独核对连续性**：信物项链、婚戒、身份饰物等按正文记录所属人物、准确外形、实际佩戴／隐藏／摘下／转交及显露时点；剧情要求优先于装饰取舍。某饰物是重要道具，不代表所有造型都须佩戴，也不能为搭配擅自换款、删去关键证据、让隐藏信物提前外露或混淆持有人。需要独立道具参考时与步骤4共享同一设计，不重复发明；同衣状态与跨镜延续沿用真实佩戴状态。
6. **写进规划与完整 Prompt**：在既有造型规划中记录上表示意字段，也可合并到原表，不重复建表。所戴首饰写清款式、材质／颜色、尺寸或长度、佩戴位置及与服装的呼应；留空时明确项链、耳饰各自不佩戴，不能只写“简约配饰”。完整英文 Prompt 按本套实际决定展开，例如需要裸颈但戴耳饰时分别写明 `no necklace, bare neck` 与具体耳饰，不能用 `no jewelry` 误删耳饰、剧情婚戒等应保留项目。不同造型不复制同一套配饰句，锁脸参考的原首饰不作为本套默认设计；不为了展示首饰改变规定构图或自动新增独立图片。
7. **以实际图片验收**：逐套查看全身与上半身近景的搭配效果，确认该留空处没有被模型补饰、该佩戴的饰物存在且款式正确；领口比例、项链落点、耳饰体量与服装相协调，无穿模、悬浮、融入皮肤或多余重复。三视图可见部位的配饰、材质颜色与戴／不戴状态一致；合理遮挡不误判漏饰。再横向检查同角色多套及同剧女性之间是否机械同款，核对剧情饰物与同衣派生状态。只有文字记录不能宣称图片搭配通过；真实问题按既有授权及返修规则处理受影响项。

### 第二阶段：提示词组装与审美标准

0. **所有人物资产的面部与画质标准**：主角、配角和反派均适用，完整定妆板与包含面部的局部参考均须落实，不仅写在说明中。

   * **统一要求**：无剧情或人设例外时，默认白皙通透、细嫩水润、均匀无瑕的面部肤质，男女主与主要配角严格执行；祛除非设定性黑眼圈、眼袋、深泪沟及皮肤瑕疵，提高脸部清晰度和细腻质感。明确肤色、真实年龄和已认可身份保留，深肤色达到同等级细嫩肤质；脸、颈肩、四肢和三视图一致。按专项规则逐项核对前10集出镜角色。
   * **真实质感**：平整无瑕不等于抹掉全部皮肤纹理。保留细微自然肤理、真实肤色、柔和明暗层次和清晰五官边缘；不使用粗大毛孔、斑驳粗糙皮肤来证明写实，也不使用塑料脸、蜡像感、过度磨皮、模糊柔焦或锐化光边制造“精致”。
   * **剧情与身份连续性**：不改变原有骨相、五官比例、年龄层、肤色和角色辨识特征。剧情明确要求的永久伤痕、识别性胎记、年龄特征或当场病伤状态须按依据保留，并删改与其冲突的无瑕／祛除描述；没有剧情依据时不添加黑眼圈、眼袋、泪沟、斑点或疲态。临时状态仍按规划／调用表处理，不因本画质要求新增状态造型。
   * **精修不改变选角定位**：皮肤平整、高清细腻属于制作要求，不等于所有人都须标准美人脸。主角也必须保留其原创骨相、眉毛浓淡毛流、眼型眼距、鼻唇比例、年龄感和气质表达；不能用精修把不同女主变成同款眉眼。反派、配角和 NPC 可以保留与设定相符的普通面容、硬朗或不对称骨相及真实年龄特征，不为提高精致度改掉身份辨识点；具体剧情特征优先于泛化美化词。
   * **落实方式**：所有包含面部的最终 Prompt 都完整写入适用的面部精修与画质要求。只展示服装、组件等不含面部的参考保留高清、干净、细节清晰要求，不为执行面部标准额外生成脸部图片。

1. **按剧情与角色定位安排外观标准**：

   * **剧情优先**：先确定这个人是谁、生活在什么时代地区、承担什么叙事作用，以及观众此时应感到什么，再决定面孔与造型。不得为美化改变正文明确的年龄、职业、外貌特征、伪装或变身前后差异。
   * **主角与核心恋爱对象**：在剧情、人设允许的范围内，强调高颜值、高质感、高吸引力及鲜明记忆点；若正文明确要求普通外貌或特殊状态，先满足设定，以气质、表演感和造型设计实现相应吸引力。
   * **反派、小配角与功能角色**：不强制非常高颜值。反派优先体现其具体设定与当下叙事定位；功能角色及 NPC 优先让身份、职能、地位和气质一眼可辨。可按剧情采用漂亮、俊美、普通或个性鲜明的面孔，不把“不必高颜值”变成必须丑化，也不以外貌或身体特征直接判定善恶。
   * **年龄感**：外貌年龄与角色设定相符；儿童体现真实儿童比例与童真，不使用成人性感描述、妆容或姿态；成熟及老年角色按身份和经历保留相应年龄感，不统一年轻化，也不强制所有长者同一种优雅气质。
   * **辨识度**：用参考研究后形成的具体骨相、眉毛、五官、发型、气质眼神及造型锚点建立角色记忆点；不复制统一网红脸，也不只堆叠高颜值、凶狠或专业等抽象形容词。允许借鉴真实人物及影视角色的优秀特征，最终形成符合本剧的原创虚构演员脸，每位主角都有独立整体风格，避免照搬单一参考。
   * **大众审美**：符合目标欧美受众和全球主流短剧审美，但允许保留自然不对称、独特骨相、眼距/眉形/鼻形/唇形差异，避免所有角色滑向同一种标准美人脸
   * **制作质感**：无论主角、反派或小配角，均须有精良选角与电影摄影质感。面孔可以普通，服装可以朴素，但清晰度、材质、布光、人体比例和身份一致性不能粗糙失真。

3. **生成要求 (Cinematic Photography Standards)**：

   * **完整定妆板构图**：需要完整定妆的服装／形体使用横版 `16:9` 三联设定板：左正面全身、中 `45°–60°` 三分之四侧面全身、右侧正面上半身近景（完整头顶至胸口下方，按服装延至腰部，双肩、领口和上衣可见，脸和发际线清晰）。三视图须同人、同年龄、同身形和同服装，不得误生成三个人。局部／组件和必要姿态参考按规划用途验收，不能因没有三联而返工，也不要求每个状态重新做一套板。
   * **基础板的白棚与空手要求**：完整定妆板使用纯白无缝背景、均匀柔光和自然表情。普通角色全身完整入画、双臂自然下垂、双手空置；身体状态角色用自然坐姿、卧姿或支撑姿势，完整展示身体及必要设备。非必要道具转步骤4按需处理。局部或动作参考按其用途展示，不要求把全身硬塞进局部图。
   * **绝对真人摄影质感**：禁止任何绘画、插图、漫画或油画感。面部须平整精致、清晰细腻，皮肤使用 `delicate natural skin microtexture` 表现细微真实肤理，同时呈现清晰发丝及精细服饰纹理；不得用粗大毛孔、皮肤瑕疵或过度磨皮代替写实。

   * **审美优先顺序 (Aesthetics Priority)**：先保证剧情背景、身份与角色定位，再匹配颜值、气质和吸引力；主角与核心恋爱对象突出吸引力，反派及功能角色突出定位和辨识度。所有角色统一保证制作质感，美化不得破坏时代、身体状态、职业功能和连续时空；不要求全员礼服，也不因此给所有人额外生成独立资产。

   * **涉及场次扫描**：每套造型必须有且只有一行 `涉及场次`，只按剧本顺序列出场次号，例如 `` `1-1`、`1-3`、`2-1`、`3-2` ``；不得重复添加 `EpXX：`、按集分组或使用分号。场次号必须直接取自冻结正式剧本，并与标题中的造型覆盖集数一致；只被提及、纯画外音或未实际出镜的场次不得计入。

   * **出场字卡扫描**：写入 `character_prompts.md` 后，必须检查文件末尾是否存在 `## 出场字卡文案`。表格必须使用 `角色名 | 字卡短语（英） | 首次出场` 三列，列名、顺序和图片参考格式一致；字卡短语必须是短英文客观身份短语，只允许职业、职位、机构身份、家族身份、亲属关系、社会身份或神祇职能，不得写成中文介绍、完整英文句子、人物小传、剧情处境、关系功能、人物评价、命运状态、爽点标签、营销口号或抽象气质词。若角色真实身份存在后续反转，字卡只写首次出场时观众已知的公开身份，不得提前剧透。若缺少该段，`character_prompts.md` 判定为未完成，必须补齐后再交付。
   * **面孔与服装母版扫描**：只检查生成清单中的图片参考，核实身份／年龄／体态、服装及状态各自来源。依赖图生成并通过后才执行下游。免生成状态检查其母版绑定及连续性，不要求状态自身的图片路径。
   * **肤质、露肤与遮盖专项核验**：按[人物肤质、脸型与服装验收](人物肤质脸型与服装验收.md)逐套核对完整提交词与实际图片，分别记录肤质、柔V脸、成年曲线与合适露肤、男女均不露点；回查前10集出镜角色覆盖。逐视图检查不透明覆盖，蕾丝、薄纱、湿衣及男性敞胸不能漏检。基准任一适用项失败不扩展依赖造型，沿用既有授权与返修次数。
   * **面部与画质验收**：对包含面部的资产检查脸部清晰度、五官细节、皮肤平整度与细腻真实质感，确认已祛除无剧情依据的黑眼圈、眼袋、泪沟和皮肤瑕疵；三联板各视图的肤色与面部处理保持一致。全图须干净、高清、细节锐利，无模糊脸、塑料感、粗糙斑驳或锐化光边。剧情特征与年龄按依据保留，局部不合格时按既有返修规则处理，不自动重生全部造型。
   * **女性脸型审美验收**：实际查看正面、三分之四面孔及全身比例，分别记录角色美感与气质、年龄、辨识度及技术质量。女主、女反派及其他主要女性首图与实际查看的适配参考对照，确认小巧柔V轮廓在正面及转面都成立。主要女性角色重点检查是否出现大脸、方脸或长脸，脸盘、颧颌、眉骨、下巴是否被无依据地放宽、加重或拉长，中下庭是否过长；横向确认不同角色的脸型是否落实各自人设，避免全剧同脸型。与已定女性美感不符时，不能仅凭清晰、同人、不同脸或衣服合格判通过。放大近景时仍按实际脸部比例判断轮廓。按上述设计边界定位根因，在已有授权与返修规则内处理受影响项；基准未通过不扩展依赖造型，明确设定和已认可身份不得被统一削脸或幼龄化。
   * **主要男性脸型生成前核验**：男主、主要男配角及主要男反派均先实际查看适配的顶级男模或男性演员正面及三分之四参考，在选角记录写明来源与具体借鉴的脸型骨相；完整 Prompt 落实协调的脸部长宽、颧颌、中下庭和下巴，避免太长、太方、太大。不得仅写“顶级男模脸”或堆砌宽方颌、长脸、大下巴；按[专项标准](人物肤质脸型与服装验收.md)转译成独立面孔，保留真实年龄与已认可身份。
   * **男主及主要男配脸部与跨剧验收**：逐张查看男主及主要男配（含主要男反派）正面、三分之四面和头颈肩比例，对照实际看过的适配男模或男演员脸型骨相，检查是否太长、太方、太大、下半脸过重，或再次使用相同眉眼鼻唇；对照可取得的近期男主图片，分别记录吸引力和辨识度。没有历史图只报告文字对照，不能填“已排除跨剧撞脸”。首图未达已定审美或仍明显重脸时，不扩展该身份依赖造型，按已有授权定位处理，不动合格历史图。
   * **配饰图片验收**：按“女性角色配饰搭配”逐套查看实际图片，检查有无、款式、领口落点、与服装的整体效果及三视图／同衣状态的一致性；不以 Prompt 已写或首饰数量多判定通过。女主首个基准的配饰缺陷须先处理，再扩展相关依赖图，避免复制到后续造型。
   * **角色定位与选角验收**：按[人物选角与跨剧差异化](人物选角与跨剧差异化.md)第6节，核对剧情适配、独立骨相五官、妆发神情、身形体态与镜头吸引力。既看单人也横向比较易混人物，包括配角之间；忽略服装和发色时，自然表情下仍应能辨认不同演员。检查是否照搬单一参考、误绑他人面孔、精修抹去区别或身体比例趋同，能取得近期主演图时再做跨剧比较。反派和 NPC 不强制美型，不提前泄露隐藏身份。实际看图、仅文字检查及未核验须分开记录，不因 Prompt 不同就填图片通过。
   * **按用途检查构图**：完整定妆板检查横版16:9、规定三视图、同人同服装、白底中性光、自然表情及适合身体状态的姿势；局部、组件和动作参考检查其设计用途、完整的关键部位与可辨识度，不套用全身三联模板。服装母版不得出现装饰性持物、非必要场景或彩色轮廓光；删除与实际状态冲突的模板句。
   * **视频身份参考验收**。按[人物资产辨识度与视频参考](人物资产辨识度与视频参考.md)核验每位角色实际交付的常规定妆图，确认其面孔、发型和衣装可辨，路径与角色及造型逐一对应。
   * **双向覆盖扫描**：核对主要角色造型分布、阶段区分、换装机会和连续性；同时查每个状态是否有制作去向、每张图是否有实际用途，不能仅靠文件计数或哈希判定无冗余。
   * **生成前审阅**：准备完整可审阅的视觉规划、实际生成 Prompt、状态调用表和出场字卡。未获本轮生成授权时交用户确认；已有授权则在其范围内执行，不为每个复用决定重复询问。
   * **工具执行**：调用 Codex 内置图片生成器逐张生成。
     * **全角色生成后检查**。每张图生成后与同剧已生成角色横向比较，覆盖配角之间及实际同框易混人物。在相近尺度先检查独立骨相五官，再检查发型轮廓及上半身衣装。结合全身核对身形与服装剪影。实际图仍易混时按原授权定向处理，核对通过后再扩展该角色依赖图。
     * **先验证基准再扩展**：优先复核或生成主角、核心恋爱对象和核心反派的身份／服装基准，确认脸、全身比例、姿态、服装、白底、构图和光线后再扩展。已有合格母版直接使用；差异大时选计划中的一套后续造型验证，不额外机械生成测试装。
     * **基准审美检查**：主角、核心恋爱对象、核心反派和高频核心配角在扩展造型前，先复核已有母版或生成缺少的基础定妆图。基准未通过前不扩展依赖图，不要求已合格角色再生一次首图。
       * 审查项包括：面孔与镜头吸引力、角色区别、服装设计与身体比例；尤其检查头颈肩关系、腰胯和四肢、站坐姿透视、服装体积及剪裁是否协调，不用固定头身数拉伸人体。完整基础板还须满足规定三视图、白底中性光、自然表情与适合身体状态的姿势，普通角色完整空手，必要设备准确。
       * 先验证角色是否符合剧情与时代背景、是否一眼可辨其当下定位，再按角色要求检查吸引力。主角与核心恋爱对象保留适合人设的高颜值及关系张力；反派、配角和 NPC 不强制美型，重点是角色成立、定位明确、具有辨识度。摄影和制作质量始终保持精良。
       * 母版出现明显选角、身体比例、服装、身份一致性、姿态、设备、构图或光线缺陷时，先定位根因，再编辑或重生；该基准通过前不扩展其依赖图。局部参考不按三联板缺视图判失败。
     * 新身份首次建图可用文生图。需要贴合服装时可独立使用服装参考，标明部位和保留范围。已有认可身份参考时直接沿用或据其编辑。锁定后不得在后续服装中重新设计脸。
     * 后续独立造型锁定相应身份和体态，实际需要的同衣派生图锁定对应服装及指定状态；不为免生成状态调用图片工具。
     * 后续图与身份、体态及服装基准比较。发生漂移时修受影响图及其依赖；同原因失败按共用返修规则处理，不无条件反复整图重生。
   * **保存命名**：生成后将图片保存到项目剧本目录下的 `character/` 文件夹，并严格使用 `character_prompts.md` 中对应条目标题作为文件名主体，即 `条目标题.png`。最终图片文件名必须包含角色编号、造型编号和 `Ep` 集数范围，严禁保存为只有角色名、造型名或无集数的文件名。
