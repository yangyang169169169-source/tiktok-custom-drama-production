# 主演审美参考

本公开版只提供审美与研究规则，不附用户原图、项目截图或参考库素材。新角色设计或获授权修订前，从[共享主演参考库](共享主演参考库.md)所配置的本地库及可访问的选角来源，实际查看适配原图；不能把本文件的文字观察当成已完成看图。

- 主要女性按本剧年龄、人设和已确认身份，观察精巧的脸部长宽、柔和颊颌过渡、自然收束的柔V轮廓与短圆颏，并独立设计眉眼鼻唇；不复制统一明星脸。
- 男主及主要男配角参考适配的顶级男模或男演员，观察协调的面部长宽、中下庭、颧颌和下巴，避免太长、太方、太大；保持各自独立面孔和自然男性气质。
- 主要角色逐套比较完整衣装，观察肩腰、衣长、材质、色彩及鞋饰妆发的关系。成年主要女性在剧情允许时提高合适露肤度，以剪裁显曲线，男女均不露点。
- 清晰正面与三分之四照片优先；滤镜、强硬光、遮发、浓妆及透视不能作为真实骨相或肤色的测量依据。来源、实际看图范围、取舍与借鉴部位记入项目既有研究区。
- 没有可用图片时如实标记研究未完成，按既有研究与授权边界推进。肤质、脸型、服装、辨识度与技术质量分别验收，执行[人物肤质、脸型与服装验收](人物肤质脸型与服装验收.md)。
