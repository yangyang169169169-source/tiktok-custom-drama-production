# 场景叙事美术与光影差异化

用于步骤3的新场景规划、完整 Prompt 与图片验收。与[场景资产生成规则](场景资产生成规则.md)配合使用；本文件负责叙事美术和光影设计，原有空间归并、文件命名、空场与生成授权边界继续执行。只更新规则不自动修改历史项目或生成图片。

## 1. 先定剧情与空间的关系，再选光色

- 读正式剧本中的国家时代、地点用途、季节天气、真实时段、人物生活条件、关键行动与剧情阶段，确认本空间此时承担考核、庇护、控制、公开展示、协作、疏离或其他具体作用。不得从“豪宅、后厨、办公室”直接套出固定场景模板。
- 在 `scene_prompts.md` 规划区建立“全剧场景叙事美术总纲”：说明主要剧情阶段、核心空间之间的关系、各自空间语汇、光色依据及必须保持的连续性。可以统一写实程度、时代材料和摄影品质，但不统一所有房间的色温、曝光、对比、装修和陈设。
- 情绪要转成可见且可信的设计：如尺度与留白、通路的收束、家具朝向、材质触感、工作痕迹、光源方向、背景亮度与局部灯光；不能只写“压迫、温暖、电影感”。这是美术判断，不能冒充原文写明的事实。
- 不预设“冷＝坏、暖＝好、暗＝高级、富＝金色、穷＝破烂”。同一种剧情作用可以用不同方案表达；同一空间也能承载多种情绪。成人亲密场景仅在正文确有关系用途时考虑克制的感官氛围，不向所有办公室、后厨或儿童场景添加性张力。
- 只继承《隐藏主厨》这类项目的设计方法：叙事阶段与空间用途决定差异，材料与灯源分别控制，保持关键区域可读。具体色板、冷暖分配、建筑布置及客户对个别图片的修改不成为其他项目的固定模板。

## 2. 逐空间细化美术与布光

每个核心物理空间在既有规划区记录下表内容，可合并为分段简报或紧凑表，不新增重复表册。支撑空间用简短条目写有效区别即可；单张生成条目仍只保留“涉及场次、Prompt”。

| 设计维度 | 应写清的内容 | 如何判断是否服务剧情 |
|---|---|---|
| 剧情与使用者 | 使用者身份、空间用途、对应场次与剧情阶段，原文明示及美术补充各是什么 | 同为餐厅、银行或住宅，也要回答“谁在这里生活／工作、此处发生什么” |
| 建筑与尺度 | 地区时代、空间体量与层高、门窗形制、入口和相邻空间、固定地理锚点 | 不能把狭小退守空间做成豪宅大堂，不能为构图移动叙事关键入口 |
| 布局与动作区 | 家具关系、通路、工作台面、交谈或对峙区域、关键设备与可用留白 | 支持原文动作和后续竖屏镜头；空场不等于空屋，不能删掉剧情需要的布置 |
| 陈设与使用痕迹 | 对应职业和生活习惯的家具器具、收纳、磨损与维护程度、局部正在使用后的状态 | 工作场所有适量工具与使用逻辑，居住场所有可信日常；不盲目堆杂物，不用污秽破损代替贫穷或压迫 |
| 材料本色与触感 | 主辅材料、粗糙或光滑、哑光或反射、软硬触感，实际本色与识别色 | 木头可以灰褐或浅米，不自动金黄；不锈钢可以中性银灰，不自动蓝染；重要证据和设备颜色保持准确 |
| 动机光源与供电 | 窗光、天光、工作灯、桌灯、舞台灯、街灯或应急灯的实际位置和开关状态 | 亮从哪里来、为什么开着；停电范围和独立电源分别记录，不凭空增设灯具或月光 |
| 光线方向与软硬 | 光从哪侧／哪扇窗进入、直射或漫射、主辅关系、反射来源和照射范围 | 写世界空间方向或固定物件关系；反打后光源不随摄影机挪到另一侧，夜景不出现无来由日光 |
| 曝光与明暗层次 | 主动作区亮度、背景相对亮暗、阴影细节、局部高光及实际所需反差 | 可用柔和通透或克制低照度；暗处保留需要阅读的信息，亮处不失去材料与证据，不统一高环境补光或全屋平亮 |
| 冷暖与色彩 | 灯源偏暖／中性／偏冷的依据、白平衡倾向、主辅色与强调色、饱和度、亮暗部色彩关系 | 把材料本色、光源颜色和最终影调分开写，不用一个“暖调／冷调”染遍所有物体；不为求异随意上彩光 |
| 纵深与取景 | 本图镜位与视角用途、前中后景的结构和明暗层次、必要反打可见区 | 不能只靠暗角或雾化制造纵深；小空间用真实尺度，不滥用超广角、宏大镜头或不必要体积光 |
| 人物与证据可读性 | 未来人物所在的头脸高度有什么可信光源或反射、手部和关键物件是否可读 | 场景图仍为空场；不为均匀脸光打开原文要求关闭的灯，不能把黑暗中应隐藏的信息提前照亮 |
| 连续性与变体 | 必须保留的门窗家具、灯具位置、时段天气、供电与装修状态；本变体只改什么 | 情绪变化不自动换装修；日夜、反打与停电变体共享固定布局和灯源地理 |

补充判断：

- **日景**：可用晴天定向光、阴天漫射、背阴窗光或窗外反射，按建筑朝向与气候安排；不全员落地窗加金色夕阳。
- **夜景**：保留真实夜色，按实际灯源和反射控制局部可读区；亮度低不必返工，但关键动作或所需脸光确实不可用时要修。无需把整个背景提成白昼。
- **压迫空间**：可用封闭布局、受限视野、冷白工作光、背景相对减光或硬质材料等适配手段，不把“压迫”直接翻译成全图欠曝。正常工作台面与通路仍须满足剧情中的使用方式。
- **亲密或归属空间**：可用局部暖白、柔和反射、适度包裹与有生活痕迹的材质，也可按剧本采用中性自然光；不因关系改善自动豪宅化或全图加橙。
- **职业／公开场景**：照明满足实际功能，工作光、展示光和观众区可以有层次；厨房的台面、比赛的识别色和关键文字要保真，不能被情绪调色吞掉。
- **使用痕迹**：描写保留在场景本身的器具、收纳、桌面使用状态即可，不写人物动作，不添加反射人影；涉及已登记道具时共享其设计与位置。

## 3. 同剧与跨剧的差异检查

### 同剧

- 在规划区建立“场景光影与布置差异表”，逐空间列出“空间／场次与叙事作用／建筑和陈设辨识点／材料本色／动机光源与明暗／影调与强调色／最易混空间及区别／连续条件”。先比较同类型、相邻剧情和同一建筑的空间。
- 不只换墙色或冷暖标签：看布局尺度、材料触感、窗光或灯具关系、使用痕迹、亮暗层次是否形成适合剧情的整体差异。不设必须全不相同的配额，共享建筑和同一机构的空间应保留家族一致性。
- 多家银行、多个出租场地等相近地点要保留各自实例：可从窗位与采光、装修年代、台柜关系、家具尺度、材料和使用程度中挑选真实区别，不能复制同一房间只改名字。
- 同一连续场景可以从求婚转为夺权、从争吵转为和解；灯光与摆设没有实际变化时保持原样，由取景和表演表达变化。真正跨日、开关灯、停电、迁居或装修时才按依据改变相应层次，并更新相关内外景和反打。
- 叙事阶段的整体变化应有真实空间或生活条件支撑，不强制“前期全冷、后期全暖”。医院走廊、支持者的小屋和公开发布厅可以在同一阶段保有各自功能。

### 跨剧

- 有可访问的近期相似项目时，选择少量同类型核心空间对照，检查是否又回到同款大理石金灯大厅、蓝灰雨巷、米白豪宅或橙黄餐厅。比较实际空间语汇和图片，不仅比较剧名或 Prompt 用词。
- 只记录实际查到的项目、来源、重合点及本剧区别；仅看文字就注明文字对照，无可用旧图不虚填图片通过，也不阻断当前独立设计。
- 保留当前故事的时代地区与叙事条件，不为求异换国家、夸大阶层或增加剧情没有的宗教与标识；旧图用于区别对照，不自动绑定为新地点的结构母版。用户指定场景延续或参考时按其要求执行。

## 4. 将设计落实到完整 Prompt

- 每条实际生成 Prompt 用英文完整写出本图的空间结构与视角、时代地区、材料本色和布置、当场光源及开关状态、方向软硬、明暗关系、光色与饱和度、动作区和未来脸部高度的可读性，最后写写实摄影、横版和空场要求。不能把专属设计留在中文规划表里，提交时只剩统一摄影后缀。
- 以具体物理描述承接剧情意图，例如窗光方向、局部工作灯、背景降低到何种相对层次、材质仍保留什么颜色；不用孤立的 `oppressive`、`luxurious`、`cinematic` 代替设计。
- 按当前图选择负向约束：防止关键区意外死黑、高光溢出、材料误染、无依据的彩光或与原文相反的天气时段。需要冷白、低照度或较强反差时，不保留禁止一切冷色／暗调／高反差的统一后缀；局部暖光也不能与“禁止任何暖色”并存。
- 不统一添加 `warm bright`、`inviting warm-neutral color palette`、`high ambient fill` 或固定暖色调色。按镜位选适合的视角和透视，不把所有房间写成同一35mm总景。写清结果所需的画面关系，比摄影品牌和“8K”等标签更重要。
- 同空间派生图传入已认可母版，明确保留结构、固定家具、材料和灯具，只改已登记的时段、供电、天气或必要布置；反打根据固定世界方向描述，不能镜像房间和光源。人物定妆仍用中性白棚，不能把场景影调固化到锁脸母版。
- 用户后续直接认可的图片成为该资产的视觉依据时，同步记录与旧 Prompt 的有效差异，后续调用按最新图和确认条件执行。只改文字不代表旧图已改变，不自动重生用户认可图。

## 5. 以实际图片验收，并把设计传给下游

1. **单图看用途**：实际查看布局、灯源、陈设与材料，判断对应剧情与场次是否成立，日夜、天气、供电、关键设备颜色和可读区是否准确。冷、暗或有反差本身不是失败；不符合设计、无动机或关键区域不可读才处理。
2. **组图看区别**：将已生成的同类和核心场景并列看现有图或缩略图，检查是否全部染黄／染蓝、是否复制相同家装和光位、是否只有标签变了。不额外生成“测试场景”；有真实区别且与设定相符即可，无需每图使用不同配色。
3. **联动看连续性**：总景、反打、内外、邻接和供电变体对照固定锚点，脸光来自可信灯源或反射，主光不会随镜位翻转。仅比较受影响链路，不牵动无关房间。
4. **检查真实清晰度**：按视频用途查看关键台面、材料、证据与构图，记录实际原生和交付尺寸、比例及有无后处理。遵循用户保留原生图、清晰度优先的偏好，常规2K目标不作为机械重生、放大或裁切理由；当次明确硬性尺寸与关键可读要求优先。
5. **记录与修复**：在既有记录里写实际已看的图、设计落实情况、差异与待修项。只完成规划时标“设计已检查，图片未生成／未核验”；实际趋同则定位统一后缀、错误参考或模型未落实，按既有授权定向修受影响图，不新增重试额度或自动返修历史资产。
6. **交接分镜**：通过空间／状态调用表传递固定布局、动作区、当场光源、时段天气、材料与强调色和状态触发条件。镜头可调整景别与曝光关系，但不能回到统一暖调、丢失原场景区别或改写灯源地理；此为资产交接，不替代分镜 Skill 的规则，也不启动视频制作。
