# 人物选角与跨剧差异化

适用于步骤2的新角色设计、人物 Prompt 和人物图片验收。男女角色均按剧情独立设计，从骨相五官、发型妆容到神情身形形成自然完整的人物；检查主角与配角，也检查配角之间的重脸风险。先实际查看适配的人物参考，再原创转译，不能靠换衣、换发色或重复美貌词制造新身份。与同目录[角色资产生成规则](角色资产生成规则.md)配合使用；不改变剧本、不自动返修历史资产、不增加生成授权或另设重试次数。

肤质、主要女性柔V脸、成年主要女性露肤与曲线及所有角色不露点，统一执行[人物肤质、脸型与服装验收](人物肤质脸型与服装验收.md)，设计、完整 Prompt 和实际看图均适用。

## 1. 从人物设定选类型，再设计面孔

- 以正式正文中的年龄、时代地区、身份经历、性格、关系表现及用户视觉要求为依据；明确写出的外貌优先保留。未写明的部分由美术设计补足，不把设计推断写成原文事实。
- **脸型随人设独立设计**：逐角色依据年龄、身份经历、气质和关系定位决定脸型，写清面部长宽、颧颌比例与下巴形态及选择依据；全剧横向检查脸型分布，避免全部角色都用同一轮廓。可属于相近脸型类别，但具体比例和骨相须能区分；亲缘等剧情必要相似保留，不为凑齐脸型种类扭曲人设，也不把职业、性格或正反派标签机械绑定某种脸型。
- 为女主选择一个主要外貌类型，必要时加一个辅助气质，说明对应的具体剧情或行为依据。甜美、可爱、冷艳、淑女、纯欲、熟女只是可选方向，可以使用明朗运动、知性干练、英气、中性、异域古典或适合本剧的其他类型，不按项目轮流抽签，不把所有词堆在同一个人身上。
- 外貌类型不等于固定性格或道德：坚强女主可以甜美，温柔女主可以冷艳；单亲母亲不自动等于熟女，财阀不自动等于冷脸。不要为了差异改变角色年龄、族裔、关系或剧情，不用族裔替代五官设计。
- 主要角色的气质类型不能自动变成保守老成的服装标签。现代女频言情和奇幻的造型审美按[角色资产生成规则](角色资产生成规则.md)中的“主要角色服装审美与阶段设计”执行；选角与服装研究分别落实，保留前期低位的剧情依据，其他适用造型主动做得更大胆、更高级且有审美感。
- 男主与其他主要角色同样定制，可按人设选温润儒雅、阳光少年感、冷峻克制、硬朗成熟、斯文知性等方向，再设计具体骨相和五官，不能所有剧都套方下颌、深眼窝、背头的同一俊男。

下表只说明如何把类型转成可见设计，不能作为跨剧重复使用的固定选角模板。每次须重新组合与本剧相符的特征：

| 类型方向 | 可转成的视觉设计 | 避免的误用 |
|---|---|---|
| 甜美 | 柔和的面部转折、舒展眉眼、亲和的眼神与唇角；脸型可圆、椭圆或其他适配形状 | 全部写成同一张大眼尖下巴娃娃脸 |
| 可爱 | 灵动眉眼、较柔和的颊部体积与轻巧表情，保留实际成年年龄和自然比例 | 把成年角色幼龄化，靠夸张大眼代替设计 |
| 冷艳 | 清晰骨相转折、克制的眉眼与表情、利落轮廓；不必同时细眼薄唇 | 把美感自动等同于恶意、冷酷或反派身份 |
| 淑女 | 协调舒展的五官、端雅仪态与适合时代的整洁发型 | 只换礼服或珠宝，面孔仍沿用其他主角 |
| 纯欲 | 成年角色的清透自然妆感、柔和眼神与克制的唇部质感，结合角色真实关系表现 | 用暴露、夸张挑逗姿势或儿童化五官代替类型 |
| 熟女 | 与真实年龄相符的成熟骨相、沉稳目光、从容姿态与细腻真实肤理 | 精修成二十岁模板脸，或靠眼袋病容硬造年龄 |

### 女性脸型与骨相的设计边界

- **用户参考先实际看图**：新女主优先实际查看当次指定图和[共享主演参考库](共享主演参考库.md)中与年龄、气质适配的女性外貌图。以清楚的正面与三分之四面观察颊颌弧线；[主演审美参考](主演审美参考.md)可补充观察方向。记录本次吸收的脸部长宽、颧颌过渡、下巴体积、眉眼关系和鼻唇比例，以及为本剧独立设计的区别。用户反馈的重点是精巧协调、柔美女性感与五官美感，不能只抽取蓝眼、金发或妆容。长期例图表达审美尺度，不是每部剧固定的身份母版；可保留不同的眼型、鼻形、唇形、成熟度与气质，不能整批套同一张脸。
- **主要女性默认小巧柔和的V形脸**：女主、女反派及其他主要女性在剧情或人设无特殊外形要求时，面颊保有自然体积，颧部到下颌沿连续柔和的曲线收窄，下颌窄于颧部，颏部短而圆润，避免中庭、下庭或下巴拉长。可随年龄、五官和气质调整收窄幅度，保留自然头颈肩比例，避免尖锥下巴、挖空脸颊、机械缩头或幼龄化。所有女性角色均检查无依据的脸部增宽、方颌加重和骨相硬化；普通配角、反派和老人仍按定位、年龄及明确外形设定设计，不强制全员美型。
- **主要女性角色重点避开大、方、长脸**：适用于女主、主要女配和女性反派。新设计尤其避免大脸盘、明显方脸及纵向拉长的长脸，检查颧颌横向体积、过长的中下庭和下巴；不能为了强势、成熟、冷艳或角色差异而主动加宽、加方、拉长。结合各自人设在精巧协调的轮廓中区分，不要求全员同款鹅蛋脸或尖下巴。正文明确外貌、用户指定方向及已认可身份母版仍优先；更新本规则不擅自改动已锁定面孔。
- **防止强硬结构叠加**：`broad forehead`、`wide jaw`、`square chin`、`pronounced cheekbones`、`hollow cheeks`、`heavy brow ridge`等词会强化相应骨骼或体积方向，不能把宽额、高外扩颧骨、凹颊、宽方颌和厚方颏叠加成女性的默认高级脸。单个特征不机械判错；须看组合后的整体效果。女王、事业型、强势、冷艳、成熟及欧美背景均不自动构成加宽脸盘或强化男性化轮廓的依据。正文明确外形、用户指定方向或已认可身份母版优先，不能为执行本条擅自换脸。
- **差异化在审美范围内完成**：继续以脸型骨相和眉眼鼻唇的真实结构区分角色，女主、女反派及其他主要女性均在柔V轮廓内，按人设调整脸颊弧度、颧宽、下颌收束与短圆颏体积；主要女性角色不以方脸、长脸或大脸盘制造差异，而通过眼型眼距、眉眼关系、鼻唇比例及下巴收束形成区别；不靠脸盘越大、下颌越方、颧骨越硬来凑差异数，也不只换发色、衣服或妆容。避免模板脸不等于排斥精致小脸；不能反向过度纠偏，也不能把所有女性统一成同款尖下巴、大眼或丰唇。
- **研究与原创转译都要看比例**：实际查看选角图时，同时观察脸的长宽、颧部横向体积、下颌宽度、颏部体积、眉骨与面颊的过渡，并判断是否符合本角色的女性美感和年龄。借鉴清晰骨相时，保留适配的柔和颊部体积与五官协调，不把参考中的某个高颧或方颏孤立放大。角色气场通过目光、神情和仪态落实，不能用粗重面部轮廓替代性格。
- **完整Prompt落实正向结构**：在每位女性自己的具体设计中，写清适用的脸部尺度、颧颌过渡、下巴形状及眉眼鼻唇比例；例如需要时使用`compact, refined facial proportions`、`soft cheek-to-jaw transitions`、`a gently tapered jaw`或`a small rounded chin`表达实际选择，不要求每人复制同一组词。提交前检查后文的雕塑感、高颧、方颏等词是否又把面孔推宽、推硬；不能只加`beautiful`、`feminine`或一串负向词掩盖前面的结构冲突。
- **美感、辨识度与技术质量分别验收**：实际查看正面与三分之四面孔。女主、女反派及其他主要女性首图对照已看过的适配参考，确认小巧面孔的面颊、颌线到颏部形成自然收束的柔V弧线，检查转面是否显方或显长；主要女性角色均检查是否出现偏离既定气质或年龄的大脸、方脸、长脸，以及无依据的脸宽、方颌、中下庭过长、凹颊或眉骨过重。结合全身图核对头颈肩、头身与面部比例。头肩特写占版面大，只能解释展示尺度，不能掩盖实际轮廓过宽过硬。清晰、同人、不同脸及服装合格均不能单独代替女性脸部审美通过，不把“有辨识度”直接写成“顶级美貌”。
- **缺陷从根因修正**：发现偏差时，区分原设计／Prompt结构冲突、参考继承、透视或模型未落实；在既有授权及返修次数内定向修正受影响项，再实际看图。不得靠浓妆、遮发、缩小预览、压窄图片或拉伸身体掩盖脸型问题；基准未通过不扩展依赖造型。规则用于后续新建及获授权修订，不自动返修历史图、不启动新生图或增加返修次数。

### 主要男性的脸型骨相、吸引力与独立面孔

- **男主与主要男配均执行**：包括主要男反派，无剧情或人设特殊外形要求时，均参考顶级男模或男性演员的协调脸型骨相，避免太长、太方、太大。按[专项标准](人物肤质脸型与服装验收.md)落实，不为拉开主配角区别故意放大、加方或拉长配角的脸。
- **先确定本剧的吸引力**：从真实年龄、关系表现、剧情阶段和目标受众出发，说明吸引力来自哪些可见组合，例如清朗眉眼与松弛笑意、精致骨相与柔和唇部、成熟轮廓与温暖目光，或利落五官与克制张力。类型可交叉，须实际研究后选择；职业、财阀、黑帮、国王或“强势”不能直接决定同款大方长脸。女性观众的偏好有差异，不把任何热帖、品牌选角或个人判断包装成统一结论。
- **多地区看图与比较**：按[共享主演参考库](共享主演参考库.md)为每位新男主及主要男配实际查看适配的顶级男模或男性演员清晰正面及三分之四图片，记录来源、具体脸型骨相优点与本角色借鉴部位；不能只写明星姓名或“顶级男模脸”。比较多种真实骨相与眉眼鼻唇组合，在现有选角记录写下本次取用的特征和与近作男主的结构差异。
- **控制面部整体比例**：分别设计面部长宽、上中下庭、颧宽与颌宽的关系、下颌转折、下巴长短与前突，再协调眉眼鼻唇。可在适配的椭圆、柔和棱角、偏心形或精练短中脸等方向中选择，保持精练协调，避免脸过大、过长或过方，不强制单一轮廓，也不把自然男性气质改成女性柔V脸。避免默认叠加`large rectangular face`、`broad square jaw`、`oversized chin`、`elongated midface`、`heavy brow ridge`；这些偏长、偏宽方或厚重的结构仅在正文、人设或用户有明确依据时保留，不能为泛化“男性气概”默认使用；不能靠`handsome`或`masculine`掩盖脸长、脸宽和下半脸过重。用户明确参考和已认可身份优先。
- **独立设计眉眼鼻唇**：写出眉毛毛流与眉峰、眉眼距离、眼型开合与眼睑、鼻梁鼻尖、嘴宽唇峰与上下唇关系，特别注意眼神可读与五官之间的协调。不能每人都是浓平眉、深凹眼窝、同款高直鼻、薄抿唇与方下巴，也不反向全员大眼、嘟唇或幼态。保留成年年龄与自然男性气质，雄性魅力不靠粗重骨骼、凶脸或超大肌肉证明。
- **跨剧对照落实到结果**：新男主选角时就对照近期相近男主的脸部结构及参考组合，在原有记录中说明本次的主要区别；首图实际生成后再看图复核。使用同款白衬衫、自然表情且暂时忽略发型时，也应能辨认不同演员。更换发色、胡须、衣服、姓名或演员参考名单均不能单独算新面孔。发现新图仍像旧男主时，先定位结构重合或参考污染，在已有授权内改未锁定的新设计；不擅改合格历史母版。
- **发型与身体服务面孔**：根据脸型、年龄及生活方式设计发际线、分缝、额前轮廓和直卷，不全员同款方发际线背头；身形在剧情要求下区分肩线、骨架、肌肉体积与站姿。自然表情的白棚板须仍有吸引力，不能靠黑白硬光、低头瞪视、腹肌或时装遮住面部设计不足。

## 2. 先看选角参考，再原创转译（新身份必须先行）

### 按剧本建立检索方向

- 为男女主、核心恋爱对象、核心反派和高频核心配角分别提炼选角简报：真实年龄段、时代地区、明确外貌要求、主要类型、剧情中的关系作用、气质气场及眼神表达。尤其主要女性角色，不只搜索“beautiful woman”“美女”或沿用上一部剧的候选名单。
- 用“年龄感＋外貌类型／关系气质＋人物或角色形象＋具体视觉目标”组合检索；需要时用目标地区语言或英文，补充如自然肖像、角色定妆、短发造型、眉眼特写等词。职业用于判断适配性，不自动绑定固定脸型。多名相近年龄女性不能都用同一组泛化搜索词。
- 检索与实际看图是角色设计的一部分，在已授权的人物规划或 Prompt 工作内自主完成，不额外增加确认轮次。这里的联网研究不自动授权图片生成。

### 找同类型、受众认可且可看清特征的图

- 本地原图与小红书同步查找。小红书用“欧美男模／欧美男演员＋本剧年龄感和气质＋脸部／定妆”等具体词查找，也研究适配女性参考及服装搭配；每个项目随人物需求更新，不把固定演员名单循环使用。取得笔记时记录真实链接、查看日期及实际看过的图片；可见时记录相关反馈及适用范围，不能编造点赞、评论或“女生公认”。公开检索无有效结果、登录受限或原图不可得时，注明“小红书研究未完成”，继续用可访问的官方演员／模特、品牌及影视图片补足研究，不为此强行安装工具、换账号或停止独立工作。用户截图可作用户审美证据，其水印不等于原帖来源已核验。
- 需要补充时使用当前可用的网页与图片检索工具，寻找符合本剧设定、具有镜头吸引力的真实演员、公众人物、模特肖像或影视角色形象。优先有来源、身份可核实的剧照、定妆照、官方肖像、采访或可靠媒体图片，不把来源不明的 AI 美女合集当作真实大众审美依据。
- 每个新主要角色通常先比较约 3–5 个候选、至少不围绕单一人物锁死；数量是研究起点，不是固定配额。有足够差异和适配证据即可收敛，没有适合的则调整检索继续找，不为凑数收图。各主要角色分别找适合自身的参考，不能整剧都从同一演员或同一套脸型衍生。
- “大众喜欢”须结合目标受众和具体角色类型判断。用确实查到的作品受欢迎情况、公开评价或受众反馈解释选择；名气与人设适配分开看。只有审美判断时明确写“美术选择”，不因搜索排序靠前就宣称大众认可，也不要求额外做受欢迎度排名。
- 必须实际查看入选参考图片的像素，观察脸部、眉毛、发型和眼神，不能只根据姓名、网页介绍、搜索摘要或图注填写视觉结论。优先清晰正面与三分之四面孔、自然表情和可辨发型的视图；强滤镜、夸张表情、浓妆或彩光仅能参考对应妆造，不据此推断真实骨相、发色或肤色。
- 在 `character_prompts.md` 规划区增加 `## 选角参考与原创转译`，每个角色用紧凑条目或表格记录：角色与选角简报、参考对象／角色及作品、来源页面与实际图片链接、已查看的视觉特征、选用与不选用的理由、具体借鉴部位、最终原创设计与区别。必要缓存只用于授权研究，按项目归位；不强制下载整套参考，不伪造图片路径或看图记录。
- 工具联网失败时先尝试当前可用的其他检索／看图路径；用户已提供的适配参考或已有核验资料可以替代并注明。没有实际看过的可用图时可继续读剧本和做暂定规划，但须标记“选角图片研究未完成”，不把文字检索冒充完成，也不直接启动该新身份的首图生成。用户当次明确要求离线或跳过研究时，按其范围执行并记录限制。

### 借鉴优点，设计本剧自己的面孔

- 可以借鉴参考人物的脸型骨相、眉形毛流、眼型眼距、鼻唇比例、发型发色、气质气场、眼神和仪态。将“哪里好、为什么适合本剧”写清，再判断该特征是否与本剧年龄、人物经历和其他角色设计兼容。
- 以多个互补参考形成设计方向，选择性吸收、重新协调成一张自然完整的原创面孔；不把几个人的五官机械拼接，也不照搬单一明星或影视角色的整套面孔、头发与表情。没有固定百分比或必须借用几个人的规定，最终整体协调与辨识度优先。
- 参考对象／作品名留在研究记录，最终 Prompt 写本角色的具体视觉特征，不用“像某某演员”“某明星同款脸”代替设计，也不反复将固定明星姓名写进所有角色的正负提示词。实际上传参考图时明确仅借鉴的部位或造型，不能把研究图片标成“面孔锁定母图”；无此需要时以文字转译即可。
- 同一参考可在确有理由时贡献某个局部优点，但不得反复沿用相同的整套参考组合，让每个女主都呈现同一骨相、同一眉毛和同一眼神。检索名单不同也不等于设计不同，须检查最终吸收的特征是否又回到默认模板。
- 在现有主菜卡中写明最终气质气场和目光的可见表达，例如眉眼松紧、注视稳定度、眼睑开合、唇部张力、头颈姿态及从容／警觉／亲和的表达；这些可以服务本剧表演，但不依赖夸张表情才能辨认身份。基础板仍保持自然表情，骨相五官独立成立。

## 3. 逐角色展开外貌设计，区分身份与妆造

在 `character_prompts.md` 现有主菜卡后增加“角色外貌细化”，每位主要角色按下表逐项写具体选择。可以按角色分段，避免挤成无法阅读的超宽表；已有信息直接引用其位置，不重复整段小传。每项以“可见设计＋剧情／美术依据”落地，不能只填“精致、英俊、温柔、纤细”。正文未规定的部分注明美术补充，不为每个鼻尖虚构一段身世解释。

| 设计维度 | 需要写清的可见内容 | 设计与连续性判断 |
|---|---|---|
| 年龄与整体方向 | 真实年龄感、外貌主类型、第一眼的整体轮廓和镜头存在感 | 按身份经历与关系表现选方向，男女均独立设计，不把职业直接等同于某种脸 |
| 脸型与骨相 | 面部长宽和上中下庭的相对关系、额头宽窄与饱满度、颧骨位置与横向体积、颊部转折、下颌角宽窄、下巴长短和圆方收束 | 按该角色人设写成协调的整体轮廓，横向避免全剧同脸型；主要女性避开大、方、长脸，不把所有美人都收成小尖下巴，不靠人为拉长、压扁面部求异 |
| 眉毛与眉眼关系 | 眉头疏密、粗细与长度、眉峰位置、眉尾方向、毛流；眉眼间距与眉骨转折 | 骨骼结构与画眉分开。换妆可以改变眉色和描画强度，不能换掉整套眉眼位置 |
| 眼睛 | 眼型、眼裂走向与开合、眼距、上眼睑覆盖、外眼角结构、眼窝与面部的衔接、虹膜色 | 眼色仅辅助；在既有男角色眼睛不太小的要求内，用眼型和眼睑等结构拉开差异，不靠小眼病容 |
| 鼻部 | 鼻根起点、鼻梁长短宽窄与走向、鼻头体积和朝向、鼻翼宽度、侧面轮廓 | 不把全员写成同款高窄直鼻，正面与三分之四侧面须属于同一结构 |
| 口唇与下半脸 | 嘴宽、唇峰清晰度、上下唇厚薄关系、自然嘴角方向、唇到下巴的空间 | 区分自然结构与口红画法；不全员丰唇、嘟唇，也不以薄唇代表恶意 |
| 肤色与年龄质感 | 无特殊要求时白皙通透、细嫩水润、均匀无瑕；既定深肤色保留基础肤色并达到同等级细嫩肤质；细微肤理与真实年龄体积 | 按人物肤质规则核对前10集覆盖及必要特例；不以粗大毛孔证明写实，不漂白已认可身份、不全员同龄、不用瑕疵求异 |
| 发际线与发型 | 发际线形状、额角露出、分缝、刘海、发长、直卷及卷度、蓬松或贴合程度、侧面和后部轮廓、准确发色 | 发际线按设定设计，不能所有男性都同款背头和整齐方发际线、所有女性都同款中分大波浪；发型随职业场合合理调整 |
| 妆容与仪容 | 底妆覆盖和光泽、修容位置与强度、画眉方式、眼线与睫毛重点、眼影色与范围、唇色和质感；男性的剃须／胡须边界、整理方式及必要自然修饰 | 按年龄、身份、场合、时代和生活方式决定，可明确无明显彩妆；不全员同款柔焦裸妆或红唇，不以重修容把不同骨相画成同一张脸 |
| 惯常神情与气场 | 自然状态的注视稳定度、眼睑松紧、唇部张力、下颌放松程度、头颈朝向与仪态；附具体行为依据 | 写可拍的克制表达，区别专注、警觉、亲和或从容；不能让每个人都冷脸瞪视或挂同款浅笑，不能用固定坏笑提前泄露反派 |
| 身形与体态 | 相对身高、头颈肩、躯干四肢、胸腰胯比例、肌肉或柔软体积及重心；成年主要女性默认曼妙、火辣而协调的曲线 | 明确成年后按人物服装规则主动显曲线与提高合适露肤度；保留独立体态和真实年龄，不全员同款身体，不对未成年人套成人设计 |
| 角色辨识组合 | 从本人的骨相、眉眼、鼻唇、发型及身形中选出最有记忆点的组合，并写最容易混淆的同剧对象与实际区别 | 自然表情、少妆、普通服装下仍应成立；不能只靠配饰、妆容、彩光、服装或夸张表情认人 |

### 稳定身份、可变妆造与当场情绪分开

- **稳定身份**：同年龄阶段的骨相、五官比例、基础肤色、发际线及身形体态基准，随已认可母版保持；剧情中的真实年龄／形体变化按对应阶段处理。
- **可变妆造**：发型整理、妆容、胡须整理、服装与配饰，按具体造型、场合及连续性决定；每套完整 Prompt 写清本套实际选择，不让身份参考中的妆发未经判断全部继承。
- **当场情绪与状态**：愤怒、疲惫、哭泣、伤势或湿发等在状态调用表和镜头中表达。身份母版采用克制自然表情，不把某一场怒容、泪妆或抿嘴永久焊在角色脸上。
- 男女主要角色均按相同深度完成设计；不能女性只写妆发、男性只写下颌和肌肉。主要儿童按[共享主演参考库](共享主演参考库.md)的合龄要求设计自然有神的眼睛、童稚脸型和有童趣的发型。普通儿童和 NPC 按用途简写有效锚点，保留年龄与定位。

## 4. 同剧整体对照，覆盖主配角与配角之间

- 在现有脸谱差异表后增加紧凑的“同剧易混角色对照”。优先比较同一性别和相近年龄、相近造型、同职业、同框及相邻集出现的人物；男主／男配／男反、女主／女配／女反都要覆盖，配角须互相比较，不能只和主演比较一次。新加入角色也对照已确认的相近角色，不按性别划界漏掉实际相似的面孔。
- 沿用主要角色间至少五项明显差异；其中应包含脸型骨相以及眉眼、鼻部、口唇中的至少两项结构区别，发型和发色仍分别检查。妆容、衣服、眼色或“气场不同”不能凑结构差异。五项是设计自查，最终仍以实际图片可辨认性判断，不编造人脸相似度百分比。
- **发型和发色分别区分**：避免同一发色、长度、分缝和卷度的近似组合。发色须在中性光下实际可辨，不能把“深棕”改名“巧克力棕”就算不同；发型须有可见轮廓差异，不能只换发夹。自然发色数量有限，不为全剧每人分配互不重复的颜色而破坏时代与人设。
- **上半身服装也要能区分**。按[人物资产辨识度与视频参考](人物资产辨识度与视频参考.md)比较实际同框易混组合的肩线、领口、内搭、材质和大色块。颜色相近时用可见结构或层次拉开，剧情指定同款时保留制服并核对脸、发型与体态。
- **脸部与身体分别对照**：先看去掉服装和头发干扰后，面部转折和五官是否独立，再看全身的肩线、比例、体积和姿态。穿同一制服、都扎工作发型时，脸和体态仍应帮助认人；不强迫每个人在每个维度都不同，也不把配角变丑来衬托主角。
- **新身份参考不得串用**：其他角色、别剧主演及整张多人角色总览不能作为新角色的身份参考；需要借鉴服装、构图或头发时分开注明用途，并避免无关面孔参与身份生成。用户已指定的身份参考优先；相同演员延续按明确要求处理。
- 剧本要求亲缘、双胞胎、替身或伪装相似时，记录相似的范围、剧情用途及观众此时是否应辨认；保留必要相似，在不破坏设定的发型、体态等处区分。正文或用户锁定相同发色时通过其他设计补足区别，不为满足计数改年龄、族裔或关系。
- 对照记录至少写“角色对／易混原因／骨相五官区别／发型发色区别／服装廓形与上半身衣装区别／身形或仪态区别／实际图片核验状态”。若两人的区别离不开服装颜色或夸张表情，重新协调尚未锁定角色的设计；已合格母版不随意改脸。普通 NPC 在既有规划中简记，不因此新增主角级档案或独立图片。

## 5. 跨剧主演对照

- 新剧首次设计主演时，优先查本生产根目录中可访问的近期已完成项目，选与当前主演年龄、类型或脸部描述最接近的少量项目作对照。先读既有 `character_prompts.md` 的主角类型和脸谱设计；有真实图片时查看已确认的清晰面孔，不只看文件名。无需遍历所有历史项目。
- 在当前 `character_prompts.md` 的规划区简记“跨剧主演对照”：实际比较的项目／角色／参考、重合风险、当前采用的骨相五官与头发区别。仅看过文字就写“文字对照”；未取得图片写“图片相似度未核验”；无可用历史资料时如实记录，不编造已排除撞脸，也不阻断独立设计。
- 同一甜美或冷艳类型可以跨剧出现，但不能重复同一套脸型骨相、眉眼鼻唇比例和头发组合。发现重合时优先调整本剧未锁定的骨相与五官设计，再配合头发，而不是仅改服装、眼色或妆容。相似度以实际视觉辨识为准，不编造数值阈值。
- 对照时也检查近期主角的选角来源组合、眉毛设计、眼神与气质表达，防止换了参考姓名却仍做成同一种风格。每部剧的新主演应有本剧专属的整体选角方案；不要求全世界从未存在的五官，也不以破坏人设来强行求异。
- 新角色首图不得绑定别剧主角为身份参考，不复制历史面孔锁定段落；历史资产只能用于区别对照。用户明确要求同一演员／角色延续时按其要求复用。同一剧的已确认角色则继续锁脸，跨剧差异规则不能造成跨服装身份漂移。
- 本次规则更新只作用于后续新建及获授权修订的角色。旧图可作对照，不自动重生成或把所有历史资产标为失效。

## 6. Prompt 与首图验收

- 每条最终人物 Prompt 完整写入本人的年龄与身份方向、脸型骨相、眉眼鼻唇组合、发际线和发型发色、肤色、身形比例及自然神情，再写本套妆容仪容、服装配饰与摄影要求。角色专属设计写在泛化美貌与精修词之前，并检查后文未把它冲掉；不用无关细节堆量，优先写能控制实际差异的结构。不得只在规划表里做差异，实际提交时又简化为“漂亮女主”“handsome man”。
- 配角 Prompt 用正向描述明确自己的五官和头发；不能仅写“不像女主”。精修保留已设计的轮廓、五官比例、有依据的轻微差异及成熟年龄特征，不把所有人磨成同一张光滑美人脸。
- 生成前检查美感、身份及妆造冲突：具体骨相是否被统一小脸／丰唇等美化词覆盖，或为追求差异而被推成不适配的宽脸方颌；独立角色是否误绑他人身份参考；同一角色的新妆发是否被旧图全部继承或反过来改了骨相身形。女性设计同时执行第1节“女性脸型与骨相的设计边界”。基础定妆板继续白底中性布光，同人四视图须保留相同设计。
- 男主及主要男配（含主要男反派）另查第1节“主要男性的脸型骨相、吸引力与独立面孔”：长宽及中下庭是否协调、眉眼鼻唇是否落实本剧选择，是否又回到大方长脸和上一剧男主的同款五官。女主对照已选用户参考的美感，检查柔和轮廓是否被雕塑感／硬朗词覆盖。分别记录脸部审美、同剧／跨剧辨识度和技术质量；任何一项不能替代其他项，参考特征本身也不能替代对实际图的判断。
- 主要角色首图先形成可比较的一组再扩展各自造型；无需把全剧 NPC 全做完才继续。逐张检查剧情适配、参考优点是否自然落实、脸与全身比例、妆发神情及精修是否保留辨识组合；再将已生成的主配角基准按易混组合横向看图。用右栏两张清晰近景比较脸部，用两张全身视图比较体态与衣装，必要时并列显示，不额外生成测试表情或另做一套图。
- 服装与脸部分别检查：主要角色实际图还须符合“主要角色服装审美与阶段设计”，核对剪裁、材质配色、妆发配饰、造型年龄感和阶段差异。脸部吸引力或角色辨识度通过，不能代替服装审美验收；没有剧情依据的老气、寡淡和过度保守仍须在既有授权范围内处理。
- **面部检查**：在尽量接近的正面或三分之四视角下，先看轮廓、颧颌和眉眼鼻唇，暂时忽略发色、服装与妆容；自然表情下仍是不同演员。**全身检查**：比较头颈肩、躯干四肢、体积与站姿，确认没有统一模特身体或同人跨造型比例漂移。视角、遮挡或像素不足时记待核验，不凭文字或文件名判通过。
- 肤质、女性脸型、成年主要女性的露肤与曲线、所有角色不露点按[专项验收](人物肤质脸型与服装验收.md)分别核对，覆盖首图与每套后续造型；不以角色区别大替代白嫩肤质或柔美女性感，也不以提高露肤度放开乳头、乳晕遮盖。
- 验收记录分别写已落实的辨识点、实际比较的角色／近期项目、图片是否已查看及待修项。只完成 Prompt 时交付“设计已检查，图片未生成／未核验”，不能宣称已杜绝重脸；没有已看图片的跨剧资料继续如实限制结论。
- 提示词不同不代表图已不同。明显撞脸、妆造趋同或形体漂移时，先定位设计重合、身份参考污染、精修过度或模型未落实，再在既有授权与返修范围内定向处理受影响角色；未通过的母版不扩展依赖造型。不自动返修已合格角色，不增加重试额度，不把修改提示词当作图片已修好。
