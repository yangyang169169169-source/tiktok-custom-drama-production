# 人物选角与跨剧差异化

适用于步骤2的新角色设计、人物 Prompt 和人物图片验收。男女角色均按剧情独立设计，从骨相五官、发型妆容到神情身形形成自然完整的人物；检查主角与配角，也检查配角之间的重脸风险。先联网研究优秀人物参考，再原创转译，不能靠换衣、换发色或重复美貌词制造新身份。与同目录[角色资产生成规则](角色资产生成规则.md)配合使用；不改变剧本、不自动返修历史资产、不增加生成授权或另设重试次数。

## 1. 从人物设定选类型，再设计面孔

- 以正式正文中的年龄、时代地区、身份经历、性格、关系表现及用户视觉要求为依据；明确写出的外貌优先保留。未写明的部分由美术设计补足，不把设计推断写成原文事实。
- 为女主选择一个主要外貌类型，必要时加一个辅助气质，说明对应的具体剧情或行为依据。甜美、可爱、冷艳、淑女、纯欲、熟女只是可选方向，可以使用明朗运动、知性干练、英气、中性、异域古典或适合本剧的其他类型，不按项目轮流抽签，不把所有词堆在同一个人身上。
- 外貌类型不等于固定性格或道德：坚强女主可以甜美，温柔女主可以冷艳；单亲母亲不自动等于熟女，财阀不自动等于冷脸。不要为了差异改变角色年龄、族裔、关系或剧情，不用族裔替代五官设计。
- 主要角色的气质类型不能自动变成保守老成的服装标签。现代女频言情和奇幻的造型审美按[角色资产生成规则](角色资产生成规则.md)中的“主要角色服装审美与阶段设计”执行；选角与服装研究分别落实，保留前期低位的剧情依据，其他适用造型主动做得更大胆、更高级且有审美感。
- 男主与其他主要角色同样定制，可按人设选温润儒雅、阳光少年感、冷峻克制、硬朗成熟、斯文知性等方向，再设计具体骨相和五官，不能所有剧都套方下颌、深眼窝、背头的同一俊男。

下表只说明如何把类型转成可见设计，不能作为跨剧重复使用的固定选角模板。每次须重新组合与本剧相符的特征：

| 类型方向 | 可转成的视觉设计 | 避免的误用 |
|---|---|---|
| 甜美 | 柔和的面部转折、舒展眉眼、亲和的眼神与唇角；脸型可圆、椭圆或其他适配形状 | 全部写成同一张大眼尖下巴娃娃脸 |
| 可爱 | 灵动眉眼、较柔和的颊部体积与轻巧表情，保留实际成年年龄和自然比例 | 把成年角色幼龄化，靠夸张大眼代替设计 |
| 冷艳 | 清晰骨相转折、克制的眉眼与表情、利落轮廓；不必同时细眼薄唇 | 把美感自动等同于恶意、冷酷或反派身份 |
| 淑女 | 协调舒展的五官、端雅仪态与适合时代的整洁发型 | 只换礼服或珠宝，面孔仍沿用其他主角 |
| 纯欲 | 成年角色的清透自然妆感、柔和眼神与克制的唇部质感，结合角色真实关系表现 | 用暴露、夸张挑逗姿势或儿童化五官代替类型 |
| 熟女 | 与真实年龄相符的成熟骨相、沉稳目光、从容姿态与细腻真实肤理 | 精修成二十岁模板脸，或靠眼袋病容硬造年龄 |

## 2. 先联网找选角参考，再原创转译（新身份必须先行）

### 按剧本建立检索方向

- 为男女主、核心恋爱对象、核心反派和高频核心配角分别提炼选角简报：真实年龄段、时代地区、明确外貌要求、主要类型、剧情中的关系作用、气质气场及眼神表达。尤其主要女性角色，不只搜索“beautiful woman”“美女”或沿用上一部剧的候选名单。
- 用“年龄感＋外貌类型／关系气质＋人物或角色形象＋具体视觉目标”组合检索；需要时用目标地区语言或英文，补充如自然肖像、角色定妆、短发造型、眉眼特写等词。职业用于判断适配性，不自动绑定固定脸型。多名相近年龄女性不能都用同一组泛化搜索词。
- 检索与实际看图是角色设计的一部分，在已授权的人物规划或 Prompt 工作内自主完成，不额外增加确认轮次。这里的联网研究不自动授权图片生成。

### 找同类型、受众认可且可看清特征的图

- 使用当前可用的网页与图片检索工具，寻找符合本剧设定、具有镜头吸引力的真实演员、公众人物、模特肖像或影视角色形象。优先有来源、身份可核实的剧照、定妆照、官方肖像、采访或可靠媒体图片，不把来源不明的 AI 美女合集当作真实大众审美依据。
- 每个新主要角色通常先比较约 3–5 个候选、至少不围绕单一人物锁死；数量是研究起点，不是固定配额。有足够差异和适配证据即可收敛，没有适合的则调整检索继续找，不为凑数收图。各主要角色分别找适合自身的参考，不能整剧都从同一演员或同一套脸型衍生。
- “大众喜欢”须结合目标受众和具体角色类型判断。用确实查到的作品受欢迎情况、公开评价或受众反馈解释选择；名气与人设适配分开看。只有审美判断时明确写“美术选择”，不因搜索排序靠前就宣称大众认可，也不要求额外做受欢迎度排名。
- 必须实际查看入选参考图片的像素，观察脸部、眉毛、发型和眼神，不能只根据姓名、网页介绍、搜索摘要或图注填写视觉结论。优先清晰正面与三分之四面孔、自然表情和可辨发型的视图；强滤镜、夸张表情、浓妆或彩光仅能参考对应妆造，不据此推断真实骨相、发色或肤色。
- 在 `character_prompts.md` 规划区增加 `## 选角参考与原创转译`，每个角色用紧凑条目或表格记录：角色与选角简报、参考对象／角色及作品、来源页面与实际图片链接、已查看的视觉特征、选用与不选用的理由、具体借鉴部位、最终原创设计与区别。必要缓存只用于授权研究，按项目归位；不强制下载整套参考，不伪造图片路径或看图记录。
- 工具联网失败时先尝试当前可用的其他检索／看图路径；用户已提供的适配参考或已有核验资料可以替代并注明。没有实际看过的可用图时可继续读剧本和做暂定规划，但须标记“选角图片研究未完成”，不把文字检索冒充完成，也不直接启动该新身份的首图生成。用户当次明确要求离线或跳过研究时，按其范围执行并记录限制。

### 借鉴优点，设计本剧自己的面孔

- 可以借鉴参考人物的脸型骨相、眉形毛流、眼型眼距、鼻唇比例、发型发色、气质气场、眼神和仪态。将“哪里好、为什么适合本剧”写清，再判断该特征是否与本剧年龄、人物经历和其他角色设计兼容。
- 以多个互补参考形成设计方向，选择性吸收、重新协调成一张自然完整的原创面孔；不把几个人的五官机械拼接，也不照搬单一明星或影视角色的整套面孔、头发与表情。没有固定百分比或必须借用几个人的规定，最终整体协调与辨识度优先。
- 参考对象／作品名留在研究记录，最终 Prompt 写本角色的具体视觉特征，不用“像某某演员”“某明星同款脸”代替设计，也不反复将固定明星姓名写进所有角色的正负提示词。实际上传参考图时明确仅借鉴的部位或造型，不能把研究图片标成“面孔锁定母图”；无此需要时以文字转译即可。
- 同一参考可在确有理由时贡献某个局部优点，但不得反复沿用相同的整套参考组合，让每个女主都呈现同一骨相、同一眉毛和同一眼神。检索名单不同也不等于设计不同，须检查最终吸收的特征是否又回到默认模板。
- 在现有主菜卡中写明最终气质气场和目光的可见表达，例如眉眼松紧、注视稳定度、眼睑开合、唇部张力、头颈姿态及从容／警觉／亲和的表达；这些可以服务本剧表演，但不依赖夸张表情才能辨认身份。基础板仍保持自然表情，骨相五官独立成立。

## 3. 逐角色展开外貌设计，区分身份与妆造

在 `character_prompts.md` 现有主菜卡后增加“角色外貌细化”，每位主要角色按下表逐项写具体选择。可以按角色分段，避免挤成无法阅读的超宽表；已有信息直接引用其位置，不重复整段小传。每项以“可见设计＋剧情／美术依据”落地，不能只填“精致、英俊、温柔、纤细”。正文未规定的部分注明美术补充，不为每个鼻尖虚构一段身世解释。

| 设计维度 | 需要写清的可见内容 | 设计与连续性判断 |
|---|---|---|
| 年龄与整体方向 | 真实年龄感、外貌主类型、第一眼的整体轮廓和镜头存在感 | 按身份经历与关系表现选方向，男女均独立设计，不把职业直接等同于某种脸 |
| 脸型与骨相 | 面部长宽和上中下庭的相对关系、额头宽窄与饱满度、颧骨位置与横向体积、颊部转折、下颌角宽窄、下巴长短和圆方收束 | 写成协调的整体轮廓，不把所有美人都收成小尖下巴；不靠人为拉长、压扁面部求异 |
| 眉毛与眉眼关系 | 眉头疏密、粗细与长度、眉峰位置、眉尾方向、毛流；眉眼间距与眉骨转折 | 骨骼结构与画眉分开。换妆可以改变眉色和描画强度，不能换掉整套眉眼位置 |
| 眼睛 | 眼型、眼裂走向与开合、眼距、上眼睑覆盖、外眼角结构、眼窝与面部的衔接、虹膜色 | 眼色仅辅助；在既有男角色眼睛不太小的要求内，用眼型和眼睑等结构拉开差异，不靠小眼病容 |
| 鼻部 | 鼻根起点、鼻梁长短宽窄与走向、鼻头体积和朝向、鼻翼宽度、侧面轮廓 | 不把全员写成同款高窄直鼻，正面与三分之四侧面须属于同一结构 |
| 口唇与下半脸 | 嘴宽、唇峰清晰度、上下唇厚薄关系、自然嘴角方向、唇到下巴的空间 | 区分自然结构与口红画法；不全员丰唇、嘟唇，也不以薄唇代表恶意 |
| 肤色与年龄质感 | 符合已知背景的肤色与底调、年龄应有的轮廓体积和细微真实肤理 | 精修皮肤不重塑骨相、不全员同龄；遵守既有非剧情性雀斑、痣和潮红限制，不用加瑕疵制造身份 |
| 发际线与发型 | 发际线形状、额角露出、分缝、刘海、发长、直卷及卷度、蓬松或贴合程度、侧面和后部轮廓、准确发色 | 发际线按设定设计，不能所有男性都同款背头和整齐方发际线、所有女性都同款中分大波浪；发型随职业场合合理调整 |
| 妆容与仪容 | 底妆覆盖和光泽、修容位置与强度、画眉方式、眼线与睫毛重点、眼影色与范围、唇色和质感；男性的剃须／胡须边界、整理方式及必要自然修饰 | 按年龄、身份、场合、时代和生活方式决定，可明确无明显彩妆；不全员同款柔焦裸妆或红唇，不以重修容把不同骨相画成同一张脸 |
| 惯常神情与气场 | 自然状态的注视稳定度、眼睑松紧、唇部张力、下颌放松程度、头颈朝向与仪态；附具体行为依据 | 写可拍的克制表达，区别专注、警觉、亲和或从容；不能让每个人都冷脸瞪视或挂同款浅笑，不能用固定坏笑提前泄露反派 |
| 身形与体态 | 相对身高、头颈肩关系、肩宽与肩线、躯干和四肢比例、腰胯关系、肌肉或柔软体积、站姿重心和身体展开程度 | 按年龄、经历、身体状态和既定要求协调；在高挑修长等既有条件内仍可区分肩线、骨架、肌肉和比例，不全员同一健身模特身材，不捏造身高事实 |
| 角色辨识组合 | 从本人的骨相、眉眼、鼻唇、发型及身形中选出最有记忆点的组合，并写最容易混淆的同剧对象与实际区别 | 自然表情、少妆、普通服装下仍应成立；不能只靠配饰、妆容、彩光、服装或夸张表情认人 |

### 稳定身份、可变妆造与当场情绪分开

- **稳定身份**：同年龄阶段的骨相、五官比例、基础肤色、发际线及身形体态基准，随已认可母版保持；剧情中的真实年龄／形体变化按对应阶段处理。
- **可变妆造**：发型整理、妆容、胡须整理、服装与配饰，按具体造型、场合及连续性决定；每套完整 Prompt 写清本套实际选择，不让身份参考中的妆发未经判断全部继承。
- **当场情绪与状态**：愤怒、疲惫、哭泣、伤势或湿发等在状态调用表和镜头中表达。身份母版采用克制自然表情，不把某一场怒容、泪妆或抿嘴永久焊在角色脸上。
- 男女主要角色均按相同深度完成设计；不能女性只写妆发、男性只写下颌和肌肉。儿童及普通 NPC 按实际用途简写锚点，保留年龄与定位，不为填满表格增加图片。

## 4. 同剧整体对照，覆盖主配角与配角之间

- 在现有脸谱差异表后增加紧凑的“同剧易混角色对照”。优先比较同一性别和相近年龄、相近造型、同职业、同框及相邻集出现的人物；男主／男配／男反、女主／女配／女反都要覆盖，配角须互相比较，不能只和主演比较一次。新加入角色也对照已确认的相近角色，不按性别划界漏掉实际相似的面孔。
- 沿用主要角色间至少五项明显差异；其中应包含脸型骨相以及眉眼、鼻部、口唇中的至少两项结构区别，发型和发色仍分别检查。妆容、衣服、眼色或“气场不同”不能凑结构差异。五项是设计自查，最终仍以实际图片可辨认性判断，不编造人脸相似度百分比。
- **发型和发色分别区分**：避免同一发色、长度、分缝和卷度的近似组合。发色须在中性光下实际可辨，不能把“深棕”改名“巧克力棕”就算不同；发型须有可见轮廓差异，不能只换发夹。自然发色数量有限，不为全剧每人分配互不重复的颜色而破坏时代与人设。
- **脸部与身体分别对照**：先看去掉服装和头发干扰后，面部转折和五官是否独立，再看全身的肩线、比例、体积和姿态。穿同一制服、都扎工作发型时，脸和体态仍应帮助认人；不强迫每个人在每个维度都不同，也不把配角变丑来衬托主角。
- **新身份参考不得串用**：其他角色、别剧主演及整张多人角色总览不能作为新角色的身份参考；需要借鉴服装、构图或头发时分开注明用途，并避免无关面孔参与身份生成。用户已指定的身份参考优先；相同演员延续按明确要求处理。
- 剧本要求亲缘、双胞胎、替身或伪装相似时，记录相似的范围、剧情用途及观众此时是否应辨认；保留必要相似，在不破坏设定的发型、体态等处区分。正文或用户锁定相同发色时通过其他设计补足区别，不为满足计数改年龄、族裔或关系。
- 对照记录至少写“角色对／易混原因／骨相五官区别／发型发色区别／身形或仪态区别／实际图片核验状态”。若两人的区别离不开服装颜色或夸张表情，重新协调尚未锁定角色的设计；已合格母版不随意改脸。普通 NPC 在既有规划中简记，不因此新增主角级档案或独立图片。

## 5. 跨剧主演对照

- 新剧首次设计主演时，优先查本生产根目录中可访问的近期已完成项目，选与当前主演年龄、类型或脸部描述最接近的少量项目作对照。先读既有 `character_prompts.md` 的主角类型和脸谱设计；有真实图片时查看已确认的清晰面孔，不只看文件名。无需遍历所有历史项目。
- 在当前 `character_prompts.md` 的规划区简记“跨剧主演对照”：实际比较的项目／角色／参考、重合风险、当前采用的骨相五官与头发区别。仅看过文字就写“文字对照”；未取得图片写“图片相似度未核验”；无可用历史资料时如实记录，不编造已排除撞脸，也不阻断独立设计。
- 同一甜美或冷艳类型可以跨剧出现，但不能重复同一套脸型骨相、眉眼鼻唇比例和头发组合。发现重合时优先调整本剧未锁定的骨相与五官设计，再配合头发，而不是仅改服装、眼色或妆容。相似度以实际视觉辨识为准，不编造数值阈值。
- 对照时也检查近期主角的选角来源组合、眉毛设计、眼神与气质表达，防止换了参考姓名却仍做成同一种风格。每部剧的新主演应有本剧专属的整体选角方案；不要求全世界从未存在的五官，也不以破坏人设来强行求异。
- 新角色首图不得绑定别剧主角为身份参考，不复制历史面孔锁定段落；历史资产只能用于区别对照。用户明确要求同一演员／角色延续时按其要求复用。同一剧的已确认角色则继续锁脸，跨剧差异规则不能造成跨服装身份漂移。
- 本次规则更新只作用于后续新建及获授权修订的角色。旧图可作对照，不自动重生成或把所有历史资产标为失效。

## 6. Prompt 与首图验收

- 每条最终人物 Prompt 完整写入本人的年龄与身份方向、脸型骨相、眉眼鼻唇组合、发际线和发型发色、肤色、身形比例及自然神情，再写本套妆容仪容、服装配饰与摄影要求。角色专属设计写在泛化美貌与精修词之前，并检查后文未把它冲掉；不用无关细节堆量，优先写能控制实际差异的结构。不得只在规划表里做差异，实际提交时又简化为“漂亮女主”“handsome man”。
- 配角 Prompt 用正向描述明确自己的五官和头发；不能仅写“不像女主”。精修保留已设计的轮廓、五官比例、自然不对称及成熟年龄特征，不把所有人磨成同一张光滑美人脸。
- 生成前检查三类冲突：具体骨相是否被统一小脸／丰唇等美化词覆盖；独立角色是否误绑他人身份参考；同一角色的新妆发是否被旧图全部继承或反过来改了骨相身形。基础三联板继续白底中性布光，同人三视图须保留相同设计。
- 主要角色首图先形成可比较的一组再扩展各自造型；无需把全剧 NPC 全做完才继续。逐张检查剧情适配、参考优点是否自然落实、脸与全身比例、妆发神情及精修是否保留辨识组合；再将已生成的主配角基准按易混组合横向看图。使用现有清晰头肩和全身视图，必要时并列显示，不额外生成测试表情或另做一套图。
- 服装与脸部分别检查：主要角色实际图还须符合“主要角色服装审美与阶段设计”，核对剪裁、材质配色、妆发配饰、造型年龄感和阶段差异。脸部吸引力或角色辨识度通过，不能代替服装审美验收；没有剧情依据的老气、寡淡和过度保守仍须在既有授权范围内处理。
- **面部检查**：在尽量接近的正面或三分之四视角下，先看轮廓、颧颌和眉眼鼻唇，暂时忽略发色、服装与妆容；自然表情下仍是不同演员。**全身检查**：比较头颈肩、躯干四肢、体积与站姿，确认没有统一模特身体或同人跨造型比例漂移。视角、遮挡或像素不足时记待核验，不凭文字或文件名判通过。
- 验收记录分别写已落实的辨识点、实际比较的角色／近期项目、图片是否已查看及待修项。只完成 Prompt 时交付“设计已检查，图片未生成／未核验”，不能宣称已杜绝重脸；没有已看图片的跨剧资料继续如实限制结论。
- 提示词不同不代表图已不同。明显撞脸、妆造趋同或形体漂移时，先定位设计重合、身份参考污染、精修过度或模型未落实，再在既有授权与返修范围内定向处理受影响角色；未通过的母版不扩展依赖造型。不自动返修已合格角色，不增加重试额度，不把修改提示词当作图片已修好。
